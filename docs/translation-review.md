# 한글 번역(Korean.csv) 검사 결과 — 2026-11-01

대사 26,799줄을 프로그램으로 모두 검사하고, 무작위로 뽑은 줄을 사람 눈으로 읽었어요.
**전체적으로 잘 돼 있어요.** 문장이 자연스럽고, 서식 태그와 [name] 같은 자리표시자도 거의 다 맞아요.
아래는 고치면 좋은 것들이에요(번역 파일의 ID로 적었어요).

## 꼭 고치면 좋은 것

**1. "시종"이 잘못 쓰인 곳**
- 경비병(guard)을 "시종"으로 옮긴 줄(7개): 0x01000000000137BF, 0x010000000002BCF6("시종경비대"), 0x010000000003028D, 0x010000000003029B, 0x01000000000302D7, 0x0100000000030311, 0x010000000003AA19
  → "경비병", "도시 경비대"로. "시종경비병"·"시종경비대"는 바꾸기를 두 번 한 흔적으로 보여요.
- 재상(Vizier)도 "시종"으로 옮겨져 있어요 → "재상"으로. (squire를 "시종"으로 옮긴 건 괜찮아요.)

**2. "크라운다" (2줄)** — 0x0100000000015A63, 0x010000000002A379 → "크라운이다".

## 작은 것

- **빈 기울임 태그 35곳**(`<i></i>`): 영어에서 기울여 강조한 낱말이 번역하면서 빠졌어요. 화면엔 안 보여서 문제는 없어요.
  예: 0x0100000000018400, 0x01000000000398E6, JournalToDo.Ch12WarCouncil 외.
- **줄바꿈이 빠진 5줄**: 0x0100000000010B8F, 0x0010000000005001, 0x0010000000005017, 0x001000000000502C, 0x0010000000005039.
  0x0100000000010B8F은 `</align>` 뒤에 글이 나와 있어 정렬이 어긋날 수 있어요.
- **"Zhongguó" → "조궁국"**: 보통 "중궈"로 적어요.

## 잘 된 것

- 인물·지명 표기가 일관돼요: 요코브 44/44, 알브레히트 192/192, 마른스 278/278, 알디스 100/100, 피시가드(대사 속).
- 서식 태그(`<i>`, `<color>` 등)는 깨진 줄이 없어요. 문단 나눔은 `<br>`로 바꿔 3,495줄 모두 지켰어요.
- 라틴어 주문은 원문 그대로 둔 게 맞아요.
