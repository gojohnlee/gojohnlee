사용자 → 무인 루프 요청 (밖에서 GitHub 앱·웹으로 이 파일을 고쳐 커밋한다)
- 요청 하나 = 한 덩어리. 첫 줄이 요청의 이름 역할을 한다. 덩어리 사이는 빈 줄.
- 요청 사이에는 빈 줄을 꼭 넣는다(붙여 써도 따로 보려고 하지만 빈 줄이 확실하다).
- 답은 history.md 맨 위에 "### 요청 · 날짜 · 이름"으로 온다: 회차는 시작하자마자 답부터 쓰고, 돌고 있는 회차가 있으면 15분 백업 때 확인해
  답 전용 세션이 15~30분 안에 답한다(질문은 바로 답, 일은 "[받음 시각]"을 앞에 붙여 두고 다음 회차가 맨 먼저 함). 가져간 요청은 루프가 이 파일에서 지운다.
- 루프가 멈춰 있으면(사용자 확인 필요·할 일 없음·진척 없음 등) 이 파일이 바뀌면 5분 안에 다시 돈다. 아주 멈추려면 loop-stop.txt를 만든다.
- 같은 걸 다시 시키려면 새로 쓴다(지워진 요청은 history.md에 남아 있다).

- 애쉬랜드 때 나눈 묶음(B1~B9 + 실제 재시작 R, codemap "시험 고르기")에 딥노스 시험(deepnorth·deepfoe·frostcave 등)과 refilltest를 더해 다시 묶고 전부 돌린다. 약식판은 만들지 않는다(decisions 16절).

멀티 시험 — 같은 PC 전용 서버 (10-31 사용자: 전체 회귀 다음, "알아서 해 봐")
- 방법: archive/risks.txt "혼자 하는 멀티 시험" C만 grep(-n -A6 '^C\. 완성 때'). Steam 무료 도구 "Valheim Dedicated Server"(앱 896660)를 이 PC에 켜고 이 PC 게임이 127.0.0.1로 손님 접속 → 게임이 진짜 "다른 컴퓨터"가 됨.
- 서버 설치: 대화 세션이 10-31에 Steam 설치 창을 띄움 → 보통 C:\Program Files (x86)\Steam\steamapps\common\Valheim dedicated server. 없으면 직접 받지 말고 NEED_USER로 "Steam 라이브러리 도구에서 Valheim Dedicated Server 설치" 부탁.
- 서버에 BepInEx·플러그인을 게임 폴더와 같게 넣고 -nographics -batchmode, 공개 안 함, 월드·비번은 시험용으로. 손님 접속·비번 입력은 시험 코드로 자동(사람 없이).
- 볼 것: 서버 쪽 Player.m_localPlayer·Chat·Minimap null 경로 예외 0 / 손님 "!" 명령 → 일꾼이 일하고 대답 / 말풍선·채팅·장비·애니메이션이 손님 화면에 보임 / 손님이 상자 열기·Alt+우클릭 등록(RPC) / 손님 옆 NPC 소유권(Workers.Reclaim) / 서버 다시 켠 뒤 일 복원. 손님 화면 것은 손님 게임 로그로 PASS·FAIL.
- 서버가 모드를 못 돌리는 등 막히면 원인·고칠 안을 history에 적고 고칠 수 있으면 고친다. 진짜 친구 접속은 사용자가 직접 플레이 때.
- 둘 다 끝나면 사용자가 직접 플레이한다(F7 창·상자 숫자 창 손맛 포함) — history 답 끝에 "직접 해 볼 것" 목록을 짧게.
