======================================================================
PC 세션(방식 B) 시작 순서 — 2026-10-20 사용자 결정: 클라우드 세션 컨텍스트가 차서 사용자 PC의 Claude Code로 넘어감
======================================================================
이 세션은 사용자 PC(Windows, 게임 설치됨, 호스트)에서 돈다. 사용자 손을 빌리지 않고 직접 빌드·실행·확인한다.
1. 저장소: git checkout valheim (발헤임 작업은 이 브랜치에만, 푸시도 valheim으로 — 사용자 승인).
2. 도구 확인: git, dotnet(.NET SDK 10), ilspycmd(dotnet tool install -g ilspycmd). 없으면 사용자에게 설치를 부탁(winget).
3. 게임 DLL: 비공개 저장소 필요 없음. 게임 폴더 C:\Program Files (x86)\Steam\steamapps\common\Valheim\valheim_Data\Managed
   (csproj가 자동으로 찾음. 다른 라이브러리면 dotnet build ... -p:ValheimRefs=<Managed 폴더>).
   게임 코드 읽기: ilspycmd -p -o <임시폴더> "<Managed>\assembly_valheim.dll" (결과는 저장소에 올리지 않음).
4. 빌드: Git Bash에서 ./scripts/valheim-build.sh (빌드 + 게임 Mono에 없는 참조 검사 + valheim/dist 복사).
   Core 테스트: dotnet test valheim/ValheimHelper/ValheimHelper.slnx
5. 게임 시험(손 안 댐): PowerShell에서
   $env:VH_DLL="<저장소>\valheim\ValheimHelper\Plugin\bin\Release\ValheimHelper.dll"; $s=[IO.File]::ReadAllText("<저장소>\scripts\valheim-test.ps1",[Text.Encoding]::UTF8); & ([scriptblock]::Create($s))
   (-File로 돌리면 PowerShell 5.1이 BOM 없는 UTF-8 한글을 깨뜨려 구문 오류. ilspycmd 없으면 dotnet tool install -g ilspycmd.
    이 PC에는 파이썬이 없다(python은 스토어 바로가기) → 파일 수정은 Edit 도구로. git 이름은 저장소 설정 Claude <noreply@anthropic.com>.)
   → 설치 → Steam으로 실행(인자 없음) → 인트로 건너뜀 → te4st41 자동 입장 → 시험 차례로 → 2초 뒤 자동 종료 → 결과 출력.
   시험 고르기: $env:VH_TEST="vh_npctest;vh_flagtest;vh_woodtest;vh_stonetest"(기본), 그 밖에 vh_preptest·vh_deathtest·vh_fighttest·vh_exploretest·vh_fartest. 월드: $env:VH_WORLD.
   사용자가 PC로 다른 게임을 하는 중이면 $env:VH_MIN='1'(창 최소화·소리 끔, 사용자 요청 2026-10-20). 켤 때 1~2초 화면이 넘어갈 수 있다.
   결과 파일: <게임>\BepInEx\plugins\ValheimHelper\diag.txt, 오류는 <게임>\BepInEx\LogOutput.log.
   게임은 사용자 PC 화면에서 켜진다 — 사용자가 PC를 쓰고 있지 않을 때 돌린다(시작 전에 한 번 물어본다).
6. dist DLL도 커밋한다(방식 A 한 줄 명령이 raw.githubusercontent의 valheim/dist를 받음).
