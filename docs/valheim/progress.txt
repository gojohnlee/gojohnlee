다음 세션 시작 순서 ("발헤임 구현 시작"이라고 하면)
1. git fetch origin valheim && git checkout valheim  (발헤임 작업은 이 브랜치에만 푸시. 사용자 승인됨)
2. ./scripts/valheim-refs.sh <스크래치 폴더>  → 공개 참조 DLL·Jötunn API 이름 목록 생성(함수 내용은 없음)
3. (완료: 게임 1.0.20) add_repo(gojohnlee/valheim-refs) → git clone --depth 1 https://github.com/gojohnlee/valheim-refs /home/user/valheim-refs.
   게임이 업데이트되면 아래 방법으로 DLL을 다시 받는다.
   최신 게임 DLL을 비공개 저장소로 받기. 대화에 이렇게 안내:
   ① GitHub에서 New repository → 이름 valheim-refs → Private 선택 → 만들기
   ② "uploading an existing file" 눌러 아래 파일 올리기
      C:\Program Files (x86)\Steam\steamapps\common\Valheim\valheim_Data\Managed\assembly_valheim.dll
      (같은 폴더의 assembly_utils.dll, assembly_guiutils.dll도 함께)
   ③ 올렸다고 말해 주면 add_repo(gojohnlee/valheim-refs)로 붙여서 실제 코드를 읽는다.
   게임 버전(메인 메뉴 오른쪽 아래 숫자)도 같이 받는다.
4. (완료) 보조 에이전트 vh-standard·vh-simple.
5. 이 대화는 지워짐. 결정 사항은 전부 CLAUDE.md 발헤임 섹션과 docs/valheim/concept-v1.txt에 있다.
