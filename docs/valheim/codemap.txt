확인된 게임 사실 (게임 1.0.20 디컴파일로 확인 — 다시 찾지 말 것, 새로 확인하면 여기에 더한다)
- 지하묘지: 늪 = 위치 SunkenCrypt1~4(1은 꺼짐), 검은숲 무덤 = Crypt2~4. 찾기 = LocationProxy ZDO s_location 해시. 입구 문 sunken_crypt_gate(Door m_keyItem, s_state≠0 열림). 안 = y+5000(InInterior y>3000), 입구·나가기는 Teleport(불러왔을 때만, 짝 pos+forward−up). 진흙 더미 mudpile2 = Destructible 체력 1 → mudpile2_frac. TestSpawnLocation은 월드 저장을 끔.
- 열쇠 문 Door: 열기 = RPC "UseDoor"(bool = Dot(문 forward, 사람−문) < 0), 주인 쪽 RPC_UseDoor가 CanInteract(애니메이터 closed) 뒤 s_state 씀. 열쇠 확인은 Interact에서만(짐 HaveItem), m_checkGuardStone → PrivateArea.CheckAccess. Character.m_boss·m_defeatSetGlobalKey(죽으면 조건 없이 SetGlobalKey), 드롭 CharacterDrop.m_drops[].m_prefab. Player.IsMaterialKnown(공유 이름) = 주운 적 있음(m_knownMaterial, 프로필 저장). GetGlobalKey(string)는 소문자로 찾음. 던전 안 물체: SpawnLocation(Full·Ghost) → DungeonGenerator.Generate → PlaceRoom이 방의 켜진 ZNetView를 다 만듦(RandomSpawn으로 꺼진 건 안 만듦) → 구역이 처음 생기면 안 물체 ZDO가 다 있음. 안은 생성기 구역 한 칸(64m 상자).
- 수리(InventoryGui.CanRepair): m_canBeReparied, ObjectDB.GetRecipe(it)의 m_repairStation·m_craftingStation 이름 == 설비 이름, Min(GetLevel,4)≥m_minStationLevel, CheckUsable(지붕 Cover≥0.7·underRoof, 불 EffectArea.IsPointPlus025InsideBurningArea). 무료, m_durability=GetMaxDurability().
- 저항 미드: SE_Stats.m_mods(List<HitData.DamageModPair> m_type·m_modifier) → Character.GetDamageModifiers가 장비·SEMan 효과까지 합침. 추위(Cold·Freezing)는 Player.UpdateEnvStatusEffects에서만 → Humanoid인 일꾼은 추위를 안 탐(냉기 미드는 냉기 피해용). 독 피해는 Character.AddPoisonDamage가 SE "Poison"(SEMan.s_statusEffectPoison)을 붙임. 바닐라 이름 MeadPoisonResist·MeadFrostResist.
- 상자 저장: Container.Load = ZDO GetByteArray(ZDOVars.s_items) → m_inventory.Load(ZPackage). Inventory.Load는 AddItem(skipValidPositionCheck=true)라 크기와 무관 → 인스턴스 없이 new Inventory(..)로 읽을 수 있음.

- AnimalAI(사슴 등)는 공격 코드 없이 Flee만. 사슴 진영은 AnimalsVeg가 아님(게임 시험에서 BaseAI.IsEnemy 통과) → Guard.IsFoe가 AnimalAI 제외.
- 몬스터 최대 체력 = 기본 × 레벨(Character.SetupMaxHealth). 별 하나 = 레벨 +1.
- 밤 = 하루 비율 0.25 이하 또는 0.75 이상(EnvMan.CalculateNight). EnvMan.m_dayLengthSec(코드 기본 1200, 프리팹 값은 미확인), GetDayFraction().
- 스킬: Skills.Skill.Raise — 쌓인 값 += m_increseStep × factor × Game.m_skillGainRate, 요구치 floor(레벨+1)^1.5 × 0.5 + 0.5.
