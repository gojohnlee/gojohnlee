확인된 게임 사실 (게임 1.0.20 디컴파일로 확인 — 다시 찾지 말 것, 새로 확인하면 여기에 더한다)
- 상자 저장: Container.Load = ZDO GetByteArray(ZDOVars.s_items) → m_inventory.Load(ZPackage). Inventory.Load는 AddItem(skipValidPositionCheck=true)라 크기와 무관 → 인스턴스 없이 new Inventory(..)로 읽을 수 있음.
----------------------------------------------------------------------
- AnimalAI(사슴 등)는 공격 코드 없이 Flee만. 사슴 진영은 AnimalsVeg가 아님(게임 시험에서 BaseAI.IsEnemy 통과) → Guard.IsFoe가 AnimalAI 제외.
- 몬스터 최대 체력 = 기본 × 레벨(Character.SetupMaxHealth). 별 하나 = 레벨 +1.
- 밤 = 하루 비율 0.25 이하 또는 0.75 이상(EnvMan.CalculateNight). EnvMan.m_dayLengthSec(코드 기본 1200, 프리팹 값은 미확인), GetDayFraction().
- 스킬: Skills.Skill.Raise — 쌓인 값 += m_increseStep × factor × Game.m_skillGainRate, 요구치 floor(레벨+1)^1.5 × 0.5 + 0.5.
  GetSkillFactor = 레벨/100, GetRandomSkillFactor = lerp(0.4,1,계수) ±0.15. Character 기본: GetSkillFactor 0, RaiseSkill은 길들인 것만,
  GetRandomSkillFactor = sqrt(0.75~1) × ZDO 값 → NPC는 재정의함. 맞힐 때 Attack이 m_character.RaiseSkill 부름. 이름 "$skill_"+종류 소문자.
- 제작: ObjectDB.m_recipes(Recipe: m_item, m_amount, m_enabled, m_craftingStation, m_minStationLevel, m_resources[m_resItem, m_amount],
  m_requireOnlyOneIngredient). CraftingStation.FindClosestStationInRange(name, pos, range), GetLevel()(확장 포함).
- 가공: Smelter(m_conversion[m_from,m_to], m_fuelItem, m_fuelPerProduct 기본 4, m_secPerProduct, m_maxOre, m_maxFuel, m_name),
  Fermenter(m_conversion[m_from,m_to,m_producedItems], m_fermentationDuration), CookingStation(m_conversion[m_from,m_to,m_cookTime], m_slots, m_fuelItem).
  CharacterDrop.m_drops[m_prefab]. ZNetScene.m_prefabs, ObjectDB.m_items.
- Inventory.CountItems(이름), GetEmptySlots(). HitData.DamageTypes.Modify(배율), ApplyArmor.
- 바닐라 RPC_Damage는 플레이어만 갑옷 계산(→ NpcPatches.ArmorCounts). 바닐라 Attack은 플레이어 도구만 닳게 함(→ 직접 깎음).
- ItemDrop.Pickup(Humanoid)의 소유권 대기는 줍는 쪽을 Player로 캐스팅 → NPC면 NRE(→ CanPickup이면 Humanoid.Pickup).
- 곡괭이 휘두름이 바위보다 땅에 먼저 닿으면 땅만 판다(Attack.SpawnOnHitTerrain → NoDig 패치).
- 순간이동은 transform과 m_body 위치를 같이 바꿔야 한다. Humanoid 길찾기는 물 위도 길로 침(→ HumanoidAvoidWater).
- Minimap.AddPin 마지막 인자가 Splatform 형식(리플렉션으로 부름), Minimap.Explore는 비공개.
- 점프: m_jumpForce 8, 앞 2, 제자리 1.49m. 플레이어 충돌체 반지름 0.49 높이 1.85.
- 소유권: 서버만 2초마다 정리(ZDOMan.Update → IsServer일 때 ReleaseZDOS → 호스트·접속자마다 ReleaseNearbyZDOS). 주인이 있는 물체는
  주인의 활동 영역 밖일 때만 남이 가져감(IsInPeerActiveArea, 주인 peer가 없으면 밖). FarZones 패치로 NPC 주변도 호스트 영역.
- 지도: Minimap.m_explored·m_exploredOthers(BitArray, 비공개), IsExplored(Vector3)는 한 점만 봄(Scout.Explored = 구역 중심).
- 생성된 구역: ZoneSystem.IsZoneGenerated(Vector2s)는 비공개(m_generatedZones). ZDOMan.FindSectorObjects(Vector2s, SimulationDistance, List<ZDO>, List<ZDO> distant=null),
  SimulationDistance(0,0)이면 그 구역만. ZoneSystem.c_ZoneSize = 64.
- ZRoutedRpc.InvokeRoutedRPC(메서드, 인자)는 서버 peer로 보내는데, 호스트면 GetServerPeerID() = 자기 id → 그 자리에서 HandleRoutedRPC(같은 프레임).
  → 호스트 시험의 ChatNet.SendAsLocal 명령은 부르는 즉시 처리된다.
- ZDO.DataRevision은 주인이 위치·속도를 써도 오른다(ZSyncTransform.OwnerSync → ZDO.SetPosition·Set(s_velHash)). 깨어 있는 통나무(TreeLog, Rigidbody)는
  맞지 않아도 계속 오름 → 깎였는지는 체력 키로 본다: TreeBase·TreeLog·Destructible = float s_health, MineRock5 = string s_health(부위별 base64),
  MineRock = float "Health"+부위(부위 = m_areaRoot 또는 자신의 자식 충돌체). (GatherJob.HealthMark)
- 바닐라 근접 공격(Attack.DoMeleeAttack)은 광선마다 가장 가까운 것 하나만 맞힌다(m_hitThroughWalls 아니면 break) → 앞에 바위가 있으면 뒤의 통나무는 안 맞는다.
  MineRock5.DamageArea는 도구 단계·피해 확인 전에 "hit mine rock 부위"를 로그에 쓴다(도끼로 바위를 쳐도 찍힘).
- 통나무 ImpactEffect: OnCollisionEnter에서 상대가 Character면 Dot(-상대속도 방향, 통나무 그 점 속도) ≥ m_minVelocity일 때 피해("Rel vel" 로그),
  종류는 프리팹 값(통나무 = HitType.Tree). 바위(MineRock5) 등 다른 IDestructible도 친다. TreeLog.RPC_Damage는 hit.m_pushForce×2로 통나무를 민다.
- ZNetView.InvokeRPC는 주인이 자기면 그 자리에서 처리된다(ZRoutedRpc.InvokeRoutedRPC: target == 자기 id → HandleRoutedRPC) → 직접 피해는 같은 프레임에 체력에 반영.
