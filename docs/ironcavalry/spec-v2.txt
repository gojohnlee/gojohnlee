======================================================================
0. 작업 지침
======================================================================

- 대상 게임은 RimWorld 1.7이다. 1.7은 .NET 10 기반이며 1.6 이하와 구조가 다르다.
- 사용자는 모든 DLC를 보유한다. 의존성은 실제 쓰는 DLC만 선언한다(메카 배양 → Biotech).
- Harmony와 모드 자체 C# DLL은 허용한다. 그 외 외부 프레임워크는 필수로 요구하지 않는다.
- Combat Extended는 사용하지 않는다.
- 실제 1.7 게임 DLL·XML Def를 확인하고 구현한다. 확인하지 않은 이름을 추측해서 쓰지 않는다.
- 빌드 성공과 게임 내 정상 작동 검증을 구분해서 보고한다.
- 실제 수행하지 않은 테스트·성능 측정은 완료했다고 보고하지 않는다.
- 파일로 확인할 수 있는 내용은 사용자에게 다시 묻지 않는다.
- 새로운 게임플레이 결정이 필요할 때만 질문한다. 범위를 임의로 넓히지 않는다.
- Def 이름, Harmony 식별자, 키 설정 이름에 고유 접두사를 쓴다. [기본안] GJL_IC_

======================================================================
1. 공통 행동 원칙
======================================================================

우선순위
1) 플레이어의 직접 명령
2) 자동 돌격·자동 후퇴
3) 평상시 작업·충전·절전

세부 원칙
- 자동 기능이 플레이어의 명령을 매 틱 덮어쓰지 않는다.
- 예외: 수동 근접 공격 또는 수동 돌격의 "같은 대상"을 유지하는 내부 후퇴·돌격은 허용한다.
  내부 행동이 바뀌어도 원래 수동 명령의 대상과 우선권은 유지한다.
  다른 직접 명령, 대상 무효화, 공격 명령 종료 시 이 의도를 정리한다.
- 다운·기절·사망·소유권 변경 등으로 행동 불가능해지면 돌격 관련 상태를 안전하게 정리한다.
- 바닐라의 필수 작업 유효성 검사와 행동 불가능 조건을 우회하지 않는다.
- 행동 취소 시 그 행동이 만든 임시 상태·예약·속도 보너스를 정리한다.

사용자의 기존 모드와의 관계
- 사용 중: 메카나이터 통제 거리 무제한 모드, 메카 자동절전 모드. 정확한 이름·동작은 집 환경에서 확인한다.
- 기존 모드를 직접 수정하지 않는다.
- 메카 통제 가능 여부(통제 거리 포함)는 바닐라 판정과 그 모드를 그대로 따른다.
  철기병 모드가 통제 거리를 따로 우회하거나 따로 제한하지 않는다.
- "돌격 최대 거리"는 강화 피해 계산용 값이며, 통제 거리나 명령 가능 거리가 아니다.

A1. 외형과 정체성
======================================================================

확정 이름: 철기병

외형 기준: 사용자가 제공한 이미지 (docs/ironcavalry/reference.png)
- 켄타우로스형 하체.
- 밝은 장갑과 어두운 관절.
- 긴 머리 장식.
- 전방으로 길게 뻗은 창.
- 원거리 무장이 없는 근접 메카.

텍스처
- 림월드 화면에서 식별하기 쉬운 방향별 스프라이트를 준비한다.
- 첫 버전은 고정 방향별 스프라이트로 충분하다. 다리 애니메이션은 필수 범위가 아니다.
- 이미지를 게임에 맞는 크기와 시점으로 재구성한다.
- 임시 외형으로 기능을 검증했다면 최종 외형 완료와 구분해서 보고한다.

======================================================================
A4. 돌격 조작  [v2 변경]
======================================================================

수동 돌격 명령
- 철기병을 선택하면 "돌격" 명령 버튼이 보인다.
- [확정] 단축키: C
  · C를 누르면 대상 지정 상태가 되고, 대상을 클릭하면 돌격 명령이 내려진다.
  · 전용 키 설정으로 만들어 게임 옵션의 키 설정 화면에서 바꿀 수 있게 한다. 기본값은 C.
  · 1.7 바닐라 기본 키와 C가 겹치는지 확인하고 결과를 구현 메모에 남긴다.
    겹치면 사용자에게 보고한다. 임의로 다른 키를 고르지 않는다.
- [확정] 철기병 여러 기를 선택한 상태에서 C → 대상 클릭 시, 선택된 철기병 모두에게
  같은 대상으로 명령한다(바닐라 명령 버튼 묶음 방식).

거리 제한 없음
- [확정] 최대 강화 거리(시작 간격 9칸, A5) 밖의 대상에게도 명령을 받아들인다.
- 대상 지정 화면에서 거리가 멀다는 이유로 대상을 거부하거나 회색 처리하지 않는다.
- 먼 대상은 기본 속도로 접근한 뒤 돌격 구간에서 돌격을 시작한다(A6).

명령을 거부하는 경우 (이 경우에만 거부하고, 이유를 짧게 표시한다)
- 바닐라 기준으로 근접 공격할 수 없는 대상.
- 대상까지 도달할 수 있는 경로가 없음.
- 철기병이 명령을 받을 수 없는 상태(다운, 통제 불가 등 바닐라 판정).
- 재사용 대기 중(아래).

재사용 대기 중
- [확정] 재사용 대기 중에는 돌격 명령을 선택할 수 없다.
  · 버튼은 회색으로 비활성화하고 남은 재사용 대기를 표시한다.
  · C를 눌러도 대상 지정 상태로 들어가지 않는다.
- [확정] 여러 기를 선택했을 때:
  · 재사용 대기가 끝난 철기병이 하나라도 있으면 버튼을 쓸 수 있고, 대기가 끝난 철기병만 명령을 받는다.
  · 선택된 철기병이 모두 재사용 대기 중이면 버튼을 비활성화한다.

자동 돌격 토글
- 자동 돌격 사용 여부 토글을 제공한다. 기본값: 켜짐.
- 토글 상태는 저장·불러오기 후 유지한다.
- 수동 명령이 자동 판단보다 우선한다.
- 자동 돌격은 실제 근접 전투 중 조건이 맞을 때만 쓴다.
  돌격하려고 할 일 없는 메카가 적을 찾아 맵을 돌아다니면 안 된다.
- [확정] 토글에는 단축키를 두지 않는다.

======================================================================
A5. 거리 정의와 초기 수치  [v2 변경]
======================================================================

거리 정의 (모든 규칙은 이 정의를 참조한다)
- 단위는 칸. 직선 거리를 쓴다. 대각선 한 칸은 약 1.41칸.
- 간격: 철기병과 대상 사이의 현재 거리.
- 유효 접근량: 돌격 구간에서 철기병이 실제로 달려서 줄인 거리. 계산법은 A7.
- 근접 공격은 대상 바로 옆(간격 약 1칸)에서 일어난다.
  따라서 정지한 대상 기준으로 유효 접근량 ≈ 시작 간격 − 1.

초기 수치 (코드와 분리한 설정값으로 둔다)
- 돌격 이동속도: 기본 이동속도의 1.5배
- 최소 강화 유효 접근량: 3칸 (정지 대상 기준 시작 간격 약 4칸)
- 최대 강화 유효 접근량: 8칸 (정지 대상 기준 시작 간격 약 9칸)
- 돌격 구간 진입 간격: 9칸 이하
- [확정] 재사용 대기: 900게임틱 (15게임초). v1의 720틱을 대체한다.
- 자동 후퇴 이동속도: 기본 이동속도의 1.5배 (돌격과 같음)
- 자동 후퇴 제한 시간: 180게임틱
- [기본안] 돌격 구간 제한 시간: (9칸 ÷ 돌격 이동속도)의 2배.
  A2 초기안 속도 4.0칸/초 기준: 돌격 6.0칸/초 → 1.5초 × 2 = 3초 = 180틱.
  기본 속도가 바뀌면 같은 공식으로 다시 계산한다.

[기본안] 피해 곡선: 3칸부터 8칸까지 직선으로 증가
- 유효 접근량 3칸 미만: 강화 없음 (1.0배)
- 3칸: 1.5배
- 4칸: 1.7배
- 5칸: 1.9배
- 6칸: 2.1배
- 7칸: 2.3배
- 8칸 이상: 2.5배 (상한)
- 칸 사이 값은 비례 계산한다. 공식: 1.5 + 0.2 × (유효 접근량 − 3)

======================================================================
A6. 돌격 처리 흐름  [v2 변경]
======================================================================

1) 명령 수락
   - 수동 명령은 A4 조건으로 받는다. 거리는 보지 않는다.
   - 자동 돌격은 근접 전투 중인 대상에 대해서만 판단한다.

2) 접근 단계 (간격이 9칸보다 클 때)
   - 기본 속도로 대상을 쫓는다. 추격 방식은 바닐라 근접 공격을 따른다.
   - 속도 보너스 없음, 충전 없음, 재사용 대기 소모 없음.
   - 이 단계에서 취소되면 재사용 대기를 쓰지 않는다.

3) 돌격 시작 판단 (간격이 9칸 이하가 된 순간, 또는 명령 시점에 이미 9칸 이하)
   - 재사용 대기 끝남 + 간격 4칸 이상 → 돌격 시작.
     재사용 대기 시작, 이동속도 1.5배, 유효 접근량 0부터 계산.
   - 간격 4칸 미만(이미 붙어 있음) → 돌격을 시작하지 않고 일반 근접 공격.
     재사용 대기는 쓰지 않는다. 자동 돌격이 켜져 있으면 A8 자동 후퇴 조건을 확인한다.
   - 재사용 대기 중(자동 돌격에만 해당. 수동 명령은 대기 중에 내릴 수 없다) →
     일반 근접 공격을 계속한다. 재사용 대기가 끝나고 위 조건이 맞으면 그때 돌격을 시작한다.

4) 돌격 구간
   - 바닐라 경로 탐색과 지상 이동을 쓴다.
   - 철기병이 한 칸 움직일 때마다 유효 접근량을 계산한다(A7).

5) 근접 거리에서 창 공격을 한 번 시도한다.
   명중·빗나감과 관계없이 첫 공격 시도에서 돌격을 소모한다.

6) 일반 근접전으로 전환하고 속도 보너스를 없앤다.

피해 처리
- 강화는 그 공격 한 번에만 적용한다.
- 단일 대상 피해만 준다.
- 밀치기·범위 피해·벽 파괴를 넣지 않는다.
- 경직은 아래 "돌격 충돌 스턴" 하나만 넣는다(v1의 "추가 경직 없음"을 사용자 결정으로 변경).
- 강화 피해가 여러 경로에서 중복 적용되지 않게 한다.
- 관통력은 피해 배율로 자동 증폭하지 않는다.
- 평상시 전체 피해 스탯을 계속 올려두는 방식은 쓰지 않는다.

돌격 충돌 스턴 [확정]
- 돌격 첫 공격이 명중했을 때만 적용한다. 빗나가면 없음. 방어로 피해가 막혀도 명중이면 적용.
- 강화가 붙은 돌격(유효 접근량 3칸 이상)에만 적용한다.
- 스턴 시간: 유효 접근량에 비례.
  · 3칸 1.5초(90틱) → 8칸 3.0초(180틱). 공식: 1.5 + 0.3 × (유효 접근량 − 3)초, 8칸 초과는 3.0초.
- 대상 체구에 따른 약화:
  · 대상 체구가 철기병(2.0)보다 크면 스턴 시간 절반.
  · 대상 체구가 철기병의 2배(4.0) 이상이면 스턴 없음.
- 연속 스턴 방지:
  · 대상이 이미 기절 중이면 시간을 늘리지 않는다.
  · 이 스턴이 끝난 뒤 3초(180틱) 동안 같은 대상은 철기병 돌격 스턴을 다시 받지 않는다(모든 철기병 공통).
- 스턴 효과는 바닐라 기절 상태를 그대로 쓴다. 새 상태 이상을 만들지 않는다.
- 메카·보스 등이 1.7에서 일반 기절에 면역이거나 다르게 반응하는지 확인하고 구현 메모에 남긴다.
- 성능: 명중 순간 한 번만 처리한다(A11).

======================================================================
A7. 충전 계산과 중단 조건  [v2 변경]
======================================================================

유효 접근량 계산
- 철기병의 위치가 실제로 바뀐 경우에만 계산한다. 정지해 있으면 충전되지 않는다.
- 한 번의 이동은 "이동 전 거리"와 "이동 후 거리"를 같은 대상 위치(그 시점의 대상 위치)
  기준으로 비교한다. 대상이 스스로 움직인 만큼은 반영하지 않는다.
- 순접근량으로 누적한다. 가까워지면 더하고, 멀어지면 뺀다.
  음수를 버리고 양수만 더하는 방식은 금지한다(왕복 악용 방지).
- 순간이동·강제 위치 변경(한 번에 1.5칸을 넘는 위치 변화)은 계산하지 않는다.
- 막혀서 움직이지 못하면 충전되지 않는다.
- 큰 우회는 순접근량 계산상 이득이 없고, 돌격 구간 제한 시간으로 길이가 제한된다.
- 실제 피해 배율은 최종 유효 접근량을 0~8칸으로 제한해 계산한다.
- 최소 3칸을 채우지 못하면 강화 피해를 주지 않는다.

돌격 정리 조건 (아래 경우 속도 보너스와 충전량을 남기지 않고 일반 전투로 돌아간다)
- 직접 명령으로 취소
- 공격 대상 변경
- 대상 사망·소멸·맵 이탈
- 경로 실패
- 다운·기절·사망
- 돌격 행동 종료
- 소유권이나 통제 조건 변경
- 돌격 구간 제한 시간 초과

재사용 대기
- 돌격 구간을 시작할 때 설정한다. 취소해도 돌려주지 않는다(인접 상태 반복 취소 악용 방지).
- 접근 단계에서 취소된 경우는 돌격이 시작되지 않았으므로 소모하지 않는다.

중복 시작 금지
- 돌격 또는 후퇴가 진행 중이면 새 자동 후퇴·돌격을 시작하지 않는다.
  재사용 대기가 끝나도 진행 중인 것이 있으면 새로 시작하지 않는다.
- 새 수동 돌격 명령을 내리면 진행 중인 돌격을 정리한 뒤 새 명령을 적용한다.
  재사용 대기 규칙은 그대로 적용된다.

======================================================================
A8. 자동 후퇴 → 돌격
======================================================================

v1 이후 사용자가 확정한 기능이다. 검토서의 "유지할 사용자 확정 사항"을 기준으로 작성했다.

[확정] 원칙: 스킬을 쓰는 것이 그냥 때리는 것보다 약해지면 안 된다.
- 후퇴할 때도 돌격과 같은 1.5배 속도로 움직인다(사용자 선택: D안).
- 원거리 공격을 하는 대상에게는 후퇴하지 않고 붙어서 계속 때린다.
- 계산상 이득이 아닐 때는 후퇴하지 않는다(아래 이득 판정).

발동 조건 (모두 충족)
- 자동 돌격 토글 켜짐.
- 근접 전투 중이며, 대상과의 간격이 4칸 미만이라 그대로는 강화를 받을 수 없음.
- 대상이 원거리 공격을 하는 대상이 아님.
  [기본안] 판정: 대상의 현재 주 공격 수단이 원거리 무기·원거리 공격이면 원거리 대상.
- 이득 판정 통과.
- 재사용 대기 끝남.
- 진행 중인 돌격·후퇴가 없음.

이득 판정 (후퇴를 시작하기 전에 한 번만 계산한다. 매 틱 계산하지 않는다)
- 예상 이득 = 돌격으로 얻는 추가 피해 − 후퇴·돌격 동안 못 넣는 평타 피해.
  · 추가 피해: 후퇴 목적지에서 기대되는 유효 접근량으로 A5 피해 곡선을 적용한 값 − 평타 1회.
  · 못 넣는 피해: (후퇴 경로 길이 + 돌격 경로 길이) ÷ 1.5배 속도 × 초당 평타 피해.
- 대상이 쫓아와서 간격이 벌어지지 않는 경우를 반영한다:
  대상의 이동속도가 철기병 후퇴 속도에 가깝거나 더 빠르면, 180틱 안에 필요한 간격(4칸 이상)을
  벌릴 수 없다고 보고 후퇴하지 않는다.
- 예상 이득이 0 이하이면 후퇴하지 않고 계속 근접 공격한다.
- 판정에 실패해도 재사용 대기를 소모하지 않는다. 다음 판정은 [기본안] 2초(120틱) 뒤.

후퇴 목적지
- 현재 공격 대상과 자기 주변 후보만으로 판단한다.
- 자기 위치 기준 8칸 이내에서 후보 칸을 최대 5개만 평가한다.
- 대상과의 간격이 최대 강화 시작 간격(9칸)에 가까운 칸을 우선한다.
- 도달할 수 있는 칸만 고른다.

진행
- 후퇴 이동속도: 기본 이동속도의 1.5배(6.0칸/초). 후퇴가 끝나거나 취소되면 원래 속도로 되돌린다.
- 후퇴 제한 시간 180틱.
- 도착하거나 제한 시간이 지나면 그 자리에서 A6 3번 판단을 한다
  (간격 4칸 이상이면 돌격, 아니면 일반 근접 공격).
- 후퇴→돌격 한 묶음에 재사용 대기 900틱을 한 번 적용한다.
  [기본안] 후퇴를 시작할 때 재사용 대기를 시작하고, 이어지는 돌격은 같은 회차로 친다.
- 수동 근접 공격·수동 돌격의 같은 대상을 유지하는 경우에도 사용할 수 있다(1장 예외).

검토 메모: 후퇴→돌격의 지속 피해 효율 (A2 수치 기준, 정지·비추격 대상)
- 계속 근접: 15초(재사용 대기 1회)당 창 7.5회 = 270 피해.
- 이전안(후퇴 4.0칸/초): 쉬는 시간 약 3.3~3.7초 → 손실 60~66 > 추가 피해 54 → 약 2~5% 손해.
- 확정안(후퇴 6.0칸/초): 쉬는 시간 약 2.7~2.9초 → 손실 48~53 < 추가 피해 54 → 이득 약 +1~6 (최대 약 2%).
- 손익분기: 쉬는 시간 3.0초.
- 처음 접근할 때의 돌격은 어차피 이동해야 하므로 순수 이득.
- 쫓아오는 적: 사람 기본 속도 4.6칸/초 기준, 철기병 후퇴 6.0칸/초와의 차이는 1.4칸/초뿐이라
  180틱 안에 4칸 이상 벌리기 어렵다 → 이득 판정에서 대부분 후퇴하지 않음.
  실제로 후퇴가 일어나는 상대는 느리거나 다른 대상을 상대 중이라 쫓아오지 않는 근접 적이다.
- 결론: 확정안으로 "스킬을 써서 약해지는" 경우는 없어지지만, 지속 피해 이득은 작다(최대 약 2%).
  이 기능의 주된 가치는 큰 한 방(최대 90)을 다시 넣는 것이다.

A11. 성능
======================================================================

목표와 보고 기준
- 철기병 약 5기 운용을 고려한다.
- 사용자 평소 처리 속도 약 900 TPS는 비교 기준이며 보장 수치가 아니다.
- 실측 없이 "틱 저하 없음" 같은 주장을 하지 않는다.

피해야 할 구현
- 매 틱 모든 폰·동물·건물 순회.
- 매 틱 돌격 경로 재계산.
- 실패한 경로를 짧은 간격으로 무한 재시도.
- 매 틱 임시 목록 생성 등 불필요한 할당.
- 철기병이 아닌 폰의 전투 동작에 무거운 Harmony 처리.

권장
- 접근 단계의 "9칸 이내 진입" 판단은 해당 철기병 자신에 대해서만, 이동할 때 또는 낮은 빈도로 한다.
- 자동 후퇴 후보는 최대 5칸.
- 이득 판정은 직선 거리로 먼저 계산하고, 통과했을 때만 선택한 후보 1곳에 바닐라 경로를 1회 요청한다.
  대상 이동속도가 후퇴 속도에 가까워 간격을 못 벌리는 경우는 경로 계산 전에 바로 제외한다.
- 돌격 충돌 스턴
  · 돌격 명중 순간 한 번만 처리한다. 매 틱 처리 없음.
  · 스턴 시간 감소는 바닐라 기절 처리가 맡는다(모든 폰에 원래 있는 처리라 추가 부담 없음).
  · 연속 스턴 방지는 "대상 → 다시 스턴 가능한 게임틱" 작은 목록 하나로 관리한다.
    모든 폰에 새 데이터를 붙이지 않는다. 확인은 돌격 명중 때만 하고, 지난 항목은 그때 정리한다.
- 상세 디버그 로그는 기본 비활성화.

A12. 구현 순서
======================================================================

1) 1.7 게임·기존 모드·빌드 환경 확인.
   - 실제 게임 버전과 빌드 번호.
   - 단축키 C의 바닐라 키 충돌 여부.
   - 어제 다른 도구로 만든 철기병 모드가 설치돼 있다면 제거 여부와 남은 파일 확인.
2) 최소 로딩 구조.
3) 배양·통제·충전·일반 근접전.
4) 수동 돌격: 단축키 C, 거리 무관 명령 수락, 접근→돌격 전환, 상태 정리 검증.
5) 자동 돌격과 자동 후퇴.
6) 저장·불러오기.
7) 외형·한국어 UI.
8) 성능 비교와 배포 폴더 정리.

작업 중 확인한 실제 1.7 API는 짧은 구현 메모로 남긴다.

A13. 필수 검증
======================================================================

기본
- 배양·출생·통제·충전 정상 작동.
- 일반 근접전 정상 작동.
- 철기병 모드 단독, 그리고 사용자 기존 모드(통제 거리 무제한, 자동절전)와 함께 사용.

조작 (v2 신규)
- 철기병 선택 후 C로 대상 지정 상태 진입.
- 키 설정 화면에서 단축키 변경 가능.
- 여러 기 선택 시 같은 대상으로 일괄 명령.
- 9칸 밖 대상(예: 30칸)에게 명령 수락 → 기본 속도 접근 → 9칸 이내에서 돌격 시작 → 강화 적용.
- 접근 단계에서 취소하면 재사용 대기 소모 없음.
- 경로가 없는 대상은 거부되고 이유가 표시됨.
- 재사용 대기 중에는 버튼이 비활성화되고, C를 눌러도 대상 지정 상태가 되지 않음.
- 여러 기 중 일부만 재사용 대기 중이면 대기가 끝난 철기병만 명령을 받음.

피해·충전
- 정지 대상, 시작 간격 4칸 → 1.5배 / 9칸 → 2.5배 배치 확인.
- 유효 접근량 3칸 미만에서 강화 없음. 상한 2.5배 적용.
- 첫 공격 명중 후 평타에 강화가 남지 않음.
- 첫 공격이 빗나가도 강화 소모.
- 대상만 이동 / 자기 왕복 / 대각선 이동 / 정지 / 순간 위치 변경으로 부당 충전 없음.
- 돌격 충돌 스턴: 3칸 1.5초 / 8칸 3.0초, 빗나감 시 없음, 3칸 미만 없음.
- 큰 대상(체구 2.0 초과) 스턴 절반, 체구 4.0 이상 스턴 없음.
- 같은 대상에 여러 철기병이 연속 돌격해도 스턴 연장 없음, 스턴 종료 후 3초간 재스턴 없음.
- 문·벽·좁은 통로·움직이는 대상 처리.

정리·중단
- 돌격 취소 후 이동속도 복원.
- 돌격 구간 제한 시간 초과 시 속도 복원.
- 대상 사망·다운·기절·경로 실패 처리.
- 돌격·후퇴 진행 중 새 자동 돌격이 시작되지 않음.

자동 후퇴
- 붙어 있을 때 후퇴 후 돌격.
- 후퇴 180틱 제한.
- 후퇴 실패 시 일반 근접 공격으로 복귀.

저장
- 저장·불러오기 후 재사용 대기·토글 유지.
- 돌격 도중 저장·불러오기 후 속도 보너스가 남지 않음.
