용도: 사용자 개인 플레이 전용. 창작마당 공개 안 함 → 번역·다른 모드 호환 작업은 하지 않는다.

현재 모드는 점수로 살 것(퍽 40 + 교리 16 = 56개, 168점)은 많은데,
점수를 버는 길은 '완성식·약초 납품'과 '2일 무사 주둔' 의뢰 두 가지가 번갈아 오는 것뿐이다.
점수만으로 전부 사려면 게임 안 시간 약 150일, 같은 의뢰를 약 38번 반복(낙관 계산).

확장은 두 방향을 모두 넣는다(사용자 결정 2026-10-25).
  방향 A. 용병이 일해서 버는 길: 전공 보상, 원정 의뢰
  방향 B. 용병 개개인의 이야기: 경력·계급·별명, 전사자 명부, 사기, 불만→이탈→배신, 경쟁 용병단 습격
퍽·교리 분기는 늘리지 않는다.

예상 영향(추정)
  - 코드: 약 2,400줄 → 약 4,000줄(약 1.7배)
  - 전부 해금까지: 약 150일 → 약 90~110일
  - 기존 저장 파일: 그대로 이어서 사용. 기존 대원은 경력 0, 사기 60에서 시작.

구현 순서(단계마다 빌드 + 자동 검사 추가 + 푸시)
  1단계 기반: 경력·계급·별명, 전사자 명부, 사기, 전공 보상, 관리창 '대원'·'명부' 탭
  2단계: 원정 의뢰 4종
  3단계: 불만→이탈→배신 사건, 경쟁 용병단 습격, 설정 항목

사용자 결정(괄호 안이 기본안. 답이 없으면 기본안으로 진행)
  D1. 배신 사건 (넣고, 설정에서 끌 수 있게. 기본 켜짐)
  D2. 원정 중 영구 사망 (허용. 실패 시 대원당 15%, 베테랑은 절반)
  D3. 진행이 빨라지는 것 (괜찮음. 설정에 '전공 보상 배율' 0~2배를 둠)

1. 경력·계급·별명 (1단계)
---------------------------------------------------------------------
대원별 기록(MemberRecord에 저장)
  참전   : 전투(Fighting) 시작 순간 출전 가능(Ready)했던 대원 +1
  처치   : 이 대원이 죽이거나 다운시킨 적 수
  구조   : 동료 구조(GJL_MC_Rescue) 완료 수
  생환   : 다운됐다가 살아난 횟수
  원정   : 원정 성공(부분 성공 포함) 수
  입단일

공적 = 참전 + 처치 + 구조 + 원정×3

계급
  계급     공적   보너스(상태효과로 부여, 기존 퍽 보너스와 합산)
  신병      0    없음
  정규      5    사격 정확도 +1%p
  고참     15    정확도 +2%p, 정신 붕괴 기준 -4%p
  베테랑   30    정확도 +3%p, 정신 붕괴 기준 -8%p, 원정 사망 확률 절반

별명: 고참이 되는 순간 이름의 별명 칸에 붙인다. 가장 두드러진 기록으로 고른다(후보 중 무작위).
  처치가 가장 많은 축     → 사신 / 도살자 / 저승사자
  구조 3회 이상           → 수호자 / 천사
  생환 3회 이상           → 불사조 / 질긴 놈
  원정 3회 이상           → 방랑자 / 길잡이
  그 외                   → 노장 / 바위 / 그림자
알림: 승급마다 메시지. 베테랑 승급은 편지(좋은 소식).

2. 전사자 명부 (1단계)
---------------------------------------------------------------------
대원이 죽으면 기록: 이름(별명 포함), 계급, 참전·처치·원정, 입단일·사망일, 사인(구역 방어 / 원정 / 기타).
관리창 '명부' 탭에서 본다. 계약이 끝나도 남는다(맵 단위 저장).
고참 이상 전사는 편지(나쁜 소식), 그 외는 메시지.

3. 사기 (1단계, 0~100, 시작 60)
---------------------------------------------------------------------
  오르는 요인                          내리는 요인
  평시·식량 충분: 하루 +2 (80에서 멈춤)   식량 부족: 하루 -8
  구역 방어 성공: +5                     후퇴로 끝난 전투: -5
  원정 성공 +5 / 대성공 +8               원정 실패: -8
  보급·주둔 의뢰 완수: +3                대원 전사: -6 (고참 이상 -10)
  불만 해소 요구 들어줌: +25             요구 거절·기한 초과: -10
효과
  80 초과 '사기 충천' : 전원 정확도 +2%p (자연 회복은 80에서 멈추므로 승리로만 도달)
  30 이하 '불만'      : 사건 사슬 시작(6장)
  15 이하 '반란 조짐' : 경고 편지
  10 이하 '반란 직전' : 배신 판정 시작
관리창 상단에 사기 막대와 상태 단어를 표시.
참고: 기존 '식량 끊긴 지 3일이면 계약 종료'는 유지. 식량 부족만으로는 사기 10까지 떨어지기 전에 계약이 끝난다.
     배신은 전사·실패가 쌓였을 때 나오는 사건이다.

4. 전공 보상 (1단계)
---------------------------------------------------------------------
전투가 '구역 내 위협 해소'로 끝나면(후퇴로 끝나면 없음) 계약 점수 지급:
  기본 1 + 그 전투에서 대원이 처치·다운시킨 적 5명당 1, 최대 3
  경쟁 용병단 격퇴 시 +2 추가
설정: 전공 보상 배율 0~2배(기본 1).

5. 원정 의뢰 (2단계)
---------------------------------------------------------------------
기존 보급·주둔 의뢰와 별도로 5일마다 원정 2건이 함께 들어온다. 하나만 수락 가능(나머지는 자동 취소), 수락 기한 2일.
출발 조건: 평시(Garrison), 출전 가능 대원이 '원정 인원 + 2' 이상(캠프에 최소 2명 남김).
인원 선정: 자동. 계급 높은 순, 같으면 건강한 순. 관리창 '대원' 탭에서 '원정 제외' 표시 가능.
원정 중: 대원이 맵에서 사라진다. 실종 처리·충원 대상이 아니다(자리 유지).
        그만큼 캠프 방어가 약해지는 것이 원정의 대가.
계약이 원정 중에 끝나면: 귀환한 대원은 바로 함께 떠난다.

  종류            인원  기간  난이도  기본 보상                          해금
  상단 호위         2   4일    10    은 600 + 산업 의약품 5               처음부터
  산적 소굴 소탕    3   3일    18    점수 2 + 은 300                      처음부터
  현상금 사냥       3   2일    26    점수 3, 대성공 시 포로 1명 데려옴     정찰 1단계
  유물 회수         4   5일    34    점수 2 + 우주 부품 2 + 반짝이 약 2    정찰 3단계
  보상은 기존 의뢰와 같은 규모 배율(퍽 10개당 +1단계)을 적용.

판정
  대원 전력   = 사격 기술 + 장비 단계×3 + 계급(신병 0 / 정규 2 / 고참 4 / 베테랑 6)
  원정대 전력 = 대원 전력 평균 + 정찰 단계×3
  성공률      = 60% + (원정대 전력 - 난이도) × 2%p, 10%~95%로 제한
  예) 초반(사격 8, 장비 0, 신병)          : 호위 56%, 소굴 40%
      중반(사격 12, 장비 2, 정규, 정찰 1)  : 호위 86%, 소굴 70%, 현상금 54%
      후반(사격 17, 장비 4, 고참, 정찰 3)  : 소굴 95%, 현상금 92%, 유물 76%
  결과(주사위 하나, s = 성공률)
    s의 1/4 안      → 대성공: 보상 1.5배(현상금은 포로), 사기 +8
    s 안            → 성공  : 보상 전부, 대원마다 20% 확률로 가벼운 부상
    남은 몫의 절반  → 부분 성공: 보상 절반, 대원마다 50% 부상, 3% 사망
    나머지          → 실패  : 보상 없음, 전원 부상, 대원마다 15% 사망, 사기 -8
    베테랑은 사망 확률 절반. 설정에서 원정 사망을 끌 수 있다(끄면 사망 대신 중상).
  부상은 귀환할 때 실제 상처로 붙는다 → 캠프에서 치료(기존 의료 흐름 그대로).
  귀환: 캠프 집결지 근처에 나타나고 결과 편지.

6. 사건 (3단계)
---------------------------------------------------------------------
불만: 사기 30 이하가 되면 의뢰 '용병단: 불만 해소' 도착(기존 의뢰와 별개).
      내용: 은 (대원 수 × 60). 수락하면 창고에서 가져가고 사기 +25.
      3일 안에 해결 안 되면 사기 -10, 이탈 발생.
이탈: 대원 1명(베테랑은 마지막 순서)이 맵 밖으로 걸어 나가 떠난다. 빈자리는 평소처럼 충원.
      불만이 계속되면 3일마다 반복.
배신: (설정으로 끌 수 있음, 기본 켜짐) 사기 10 이하가 2일 이어지면 발생.
      대원 절반(올림)이 적대 세력으로 돌아서 정착지를 공격, 나머지는 떠난다. 계약 종료. 큰 위협 편지.
경쟁 용병단 습격: (설정으로 끄기·간격 조절) 계약 후 15일이 지나면 20~35일 간격 무작위.
      규모: 그 시점 습격 점수의 70% + 산 퍽 10개당 +10%.
      캠프에서 가까운 맵 가장자리에 나타나 캠프로 돌격. 적은 바닐라 해적 쪽 용병 병종(구현 때 이름 확인).
      격퇴 시 전공 +2, 사기 +5.

7. 관리창 (1단계부터)
---------------------------------------------------------------------
  - 상단: 사기 막대 + 상태 단어
  - 큰 탭 3개: '퍽'(지금 화면) / '대원' / '명부'
  - 대원 탭: 대원별 계급·별명·참전·처치·원정·상태(캠프 / 원정 중 / 부상), '원정 제외' 체크
  - 명부 탭: 전사자 목록

8. 설정 추가 (3단계)
---------------------------------------------------------------------
  배신 사건 켜기(기본 켬), 경쟁 용병단 습격 켜기(기본 켬) + 간격 배율,
  원정 사망 켜기(기본 켬), 전공 보상 배율(기본 1)

9. 뺀 것과 이유
---------------------------------------------------------------------
  - 퍽·교리 분기 추가: 고를 거리는 이미 충분. 밸런스·저장 호환 부담만 커진다.
  - 정착민과의 친분 관계: 작업량에 비해 눈에 띄는 효과가 작다.
  - 원정 지역을 실제 맵으로 만들어 싸우게 하는 방식: 볼거리는 있지만 맵 생성·길찾기·대원 이동 때문에 버그 위험이 크다.
    추상 판정으로 시작하고, 플레이 후 원하면 다시 검토.
  - 번역·다른 모드 호환: 개인 플레이 전용이라 필요 없다.
