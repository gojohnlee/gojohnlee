## 확인된 게임 사실
- Korean.csv 읽기(LocalizationManager, 11-03 디컴파일): 1·2줄이 header1·header2 문구와 똑같아야 하고 3줄은 줄 수(다르면 경고 창). 줄마다 칸 3개, 2번째(EN) 칸이 비면 그 줄은 버림(EN 내용은 안 씀). 0x로 시작하는 ID는 대사, [..]는 호칭 표(/로 나눔), 나머지는 글자 키. → template.csv가 필요한 이유: 이 꼴·줄 수·단락별 <align=left> 정보(규칙으로 못 만듦: 0x인데 정렬 없는 줄 1,122개).
- 번역: LocalizationManager가 persistentDataPath/Languages/*.csv 첫 파일을 찾아 매번 "Localization file found … use this?" 창(AlertDialog)을 띄움. Yes여야 적용.
- 글꼴: 대사·메뉴 TMP(PERTILI SDF 등). 책은 BookReadingManager.defaultFontAsset / Book.fontAssetOverride.
- 해상도는 HKCU\Software\Psychic Software\TheNecromancer "Screenmanager *"에 저장(기본 1920x1080, Fullscreen mode 1).

## UI 문자열
- 한글 패치 1.0의 Assembly-CSharp.hdiff는 같은 크기 제자리 덮기(SHDiff)인데, 0으로 채운 옛 파일에 적용해도 한글이 조각나 복원 불가 → 새 게임 코드에서 화면 문자열을 골라 다시 번역.
- dist/KoreanFont/ui-ko.tsv: `영어<TAB>한국어`, `=`로 시작하면 통째 일치만, 아니면 부분 바꾸기(긴 것부터). \n은 줄바꿈. 모드는 TMPro_EventManager.TEXT_CHANGED_EVENT에서 바꾼다.
- 하수인 명령 메뉴는 SamsContextMenu.menuText(정적 배열)를 직접 바꾼다.
- 이 게임 mscorlib엔 string.Replace(string,string)도 없음 → IndexOf(…, Ordinal)+Substring으로 직접.
- 게임이 매 프레임 영어를 다시 넣는 글(빠른 설정 창 등)은 이벤트로 바꿔도 다음 프레임에 덮임 → 한 번 바꾼 TMP 글을 기억해 Runner.LateUpdate에서 그리기 전에 다시 바꾼다(글이 그대로면 건너뜀).
- 능력치 이름은 Korean.csv 설명과 같게: 힘·민첩·체질·통찰·지식·관찰(Investigate)·분석·매력(Impress)·설득. Van Elstrik = 반 엘스트릭.
