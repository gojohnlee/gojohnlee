- 대화 속 아이템(11-04): 퀘스트 표·보상 표는 없음. 대화 흐름의 Item 노드(linkToInventoryItem, isItemDrop=1이면 플레이어가 건넴)가 주고받기, 조건 핀(ArticyPin.expressions unparsedExpression)이 '가졌나'를 봄. 전부 ArticyPlayer.models(Dictionary<long,ArticyModel>, hasBeenVisited 저장됨)·pins에 실행 중 들어 있음. 원본 JSON은 게임 에셋(TextAsset)이라 클라우드엔 없음 → 모드 GraphDump가 NecroHelper\\dialogue-graph.tsv로 한 번 저장(게임 회사 자료: 공개 저장소에 올리지 않음).

- 카메라 RtsCamera(11-04): Tilt 90=수직, LateUpdate가 Tilt를 MinTilt~MaxTilt, 거리를 MinDistance~MaxDistance(실내는 …Indoors)로 자름. 값은 장면 저장(코드 기본 30~85·8~32). 성문 안팎을 바꾸는 코드는 없음(TownGatesTrigger.playerIsInsideTown만 바뀜). 모드 WideCam이 성 밖 야외에서 MinTilt≤15·MaxDistance×1.6, 처음 나갈 때 Tilt>35면 35로, 돌아오면 원래 값.

## UI 문자열
- 한글 패치 1.0의 Assembly-CSharp.hdiff는 같은 크기 제자리 덮기(SHDiff)인데, 0으로 채운 옛 파일에 적용해도 한글이 조각나 복원 불가 → 새 게임 코드에서 화면 문자열을 골라 다시 번역.
- dist/KoreanFont/ui-ko.tsv: `영어<TAB>한국어`, `=`로 시작하면 통째 일치만, 아니면 부분 바꾸기(긴 것부터). \n은 줄바꿈. 모드는 TMPro_EventManager.TEXT_CHANGED_EVENT에서 바꾼다.
- 하수인 명령 메뉴는 SamsContextMenu.menuText(정적 배열)를 직접 바꾼다.
- 이 게임 mscorlib엔 string.Replace(string,string)도 없음 → IndexOf(…, Ordinal)+Substring으로 직접.
- 게임이 매 프레임 영어를 다시 넣는 글(빠른 설정 창 등)은 이벤트로 바꿔도 다음 프레임에 덮임 → 한 번 바꾼 TMP 글을 기억해 Runner.LateUpdate에서 그리기 전에 다시 바꾼다(글이 그대로면 건너뜀).
- 능력치 이름은 Korean.csv 설명과 같게: 힘·민첩·체질·통찰·지식·관찰(Investigate)·분석·매력(Impress)·설득. Van Elstrik = 반 엘스트릭.
