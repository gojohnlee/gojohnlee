## 구간 12 (줄 12000–12999)
### 줄거리
- 배경 전체: 백부 제르베스가 성(keep)에서 연 무도회. 주인공의 목적은 손님들 눈을 피해 위층 백부 집무실로 숨어들어 아버지 죽음의 증거를 찾는 것 → 손님 하나를 꼬드겨 "주의 돌리기(distraction)"를 얻거나 '그림자 걷기' 주문을 쓴다. 대화마다 선택지로 갈라지고, 실수하면 손님들이 주인공을 "슬픔에 미쳤다"고 수군댄다.
- 무도회장엔 주인공에게만 들리는 유령 셋(유령 신부·유령 신랑·유령 구울)이 끼어든다. 대답을 잘못하면 유령 말에 대꾸한 꼴이 되어 의심을 산다. 또 칼부림·목 조르기 같은 끔찍한 장면이 자주 나오지만 대부분 **환각**이고 곧 "아무 일도 없었다"로 돌아온다.
- (줄 12000~) 아그네스 카넬 부인과의 대화: 손가락을 꺾어 무릎 꿇리기, 칼 든 손님들 환각, 이항계수·확률 수학 이야기(드 무아브르와의 편지). 갈래에 따라 유혹 → 남편 카넬 경 집무실에서 정사(성인 장면, 유령 신부가 "내 남편과!" 하고 끼어듦). (줄 12120~) 카넬 경에게 아내 추문을 흘려 질투를 부추기는 갈래.
- (줄 12148~) 오스만 대신 알리 무스타파 파샤와 그의 지니(공중에 뜬 마신, 주인공의 영혼 잘라를 알아봄). 튀르크어로 말하면 비밀 이야기 가능. 파샤는 경비대장 윌러드(성 베르너)에게 관심 → 만남을 주선해 주면 주의를 돌려 주겠다는 거래. (줄 12255~) 파샤를 억지로 부리려다 지니의 어둠에 갇히는 갈래. (줄 12270) 파샤가 제르베스와 다투고 제르베스가 파샤를 때림.
- (줄 12326~) 영국 시인 알렉산더 포프: 키 작은 풍자 시인, 전쟁(리치 전쟁)과 제르베스의 과거를 캐러 옴(첩자 의심). 「불행한 여인을 추모하는 시」 낭송으로 주의 돌리기(줄 12478~12486, 시 구절).
- (줄 12488~) 무도회 입장 장면(시간상 처음): 윌러드가 이름을 알림, 유령 부부·구울 첫 등장.
- (줄 12508~) 미테르에서 온 부부 마리야(직물 회사 사장)·스타니슬라브의 수다. 서로 말을 이어받는 부부 만담. 양모 판매, 재단사 아랄드 이야기, 이혼·전처 브라나 갈등 갈래.
- (줄 12711~12727) 그림자 걷기 주문 시전 안내문.
- (줄 12728~) 백부 제르베스와 대화: 무도회·손님 소개, 아버지 장례(Grim), 어머니 줄리아나의 수면약(정체를 말하면 체포 갈래), 사촌 루커스, 남작 업무·여왕. 비난하면 경비병에게 끌려 나가는 갈래. 단검 환각(줄 12957~12986).
- (줄 12991~) 숙모 미라벨(벨 숙모)과 대화 시작.
### 인물 (이 구간에 나오는 주요 인물, 대사 많은 순)
- 제르베스(Jervase): 남작, 주인공의 백부이자 아버지 살해 용의자 / 겉은 호탕, 속은 경계·위협, 의심나면 눈을 가늘게 뜸 / 조카를 계속 떠보고 비난엔 차갑게 경비병 호출 / 주인공에게 반말(해라체, 다정한 척하는 윗사람 말투), 경비병엔 명령조 / 주인공 → 해요체("백부님"), 도발 선택지는 비꼬는 해요체.
- 알리 무스타파 파샤(Ali Mustafa Pasha): 술탄 마흐무드의 대신(오스만 외교관) / 화려한 옷, 능글맞고 꽃말 같은 정중함, 주인공을 "young one"(젊은이) / 호의와 경고를 오감 / 주인공에게 하오체 제안(연장자 외교관의 점잖은 말투) / 주인공 → 정중한 해요체·합쇼체("파샤").
- 알렉산더 포프(Alexander Pope): 영국 풍자 시인, 병으로 키가 작음 / 고풍·현학적인 말, "Nay", 라틴풍 단어 / 주인공을 떠보다 공격받으면 우아하게 반격 / 하오체+예스러운 어휘 제안 / 주인공 → 해요체("포프 선생").
- 아그네스 카넬 부인(Lady Agnes Carnell): 카넬 경의 아내, 주인공보다 15살 위, 수학 천재 / 도도·지루해함, 남편을 경멸 / 무시 → 흥미 → 유혹 갈래 / 하오체 제안(귀부인의 오만함), 정사 장면에선 반말 가능 / 주인공 → 해요체.
- 마리야(Marija)·스타니슬라브(Stanislav): 미테르의 귀족 부부, 미라벨의 친구 / 마리야는 수다·장사꾼 기질, 스타니슬라브는 순진하게 고인 얘기를 꺼냄, 서로 말을 끊고 이어받음 / 주인공에게 다정한 해요체, 부부끼리는 반말("여보") / 주인공 → 해요체.
- 지니(Djinn): 파샤의 하인 마신 / 주인공을 "this one"(이자)으로 3인칭 지칭, 오만 / 해라체 제안.
- 유령 신부·유령 신랑(Ghost Bride/Groom): 혼례날 죽은 부부(신랑이 무언가 "계획"을 숨김) / 신부는 히스테릭, 신랑은 비밀 많음 / 반말·해라체.
- 유령 구울(Ghost Ghoul): 이 성을 지은 옛 주인(추정), 오스만을 "땅을 빼앗은 적"으로 증오 / 거칠고 비꼼, 해라체.
- 리처드 카넬 경(Lord Richard Carnell): 제르베스의 고문, 영국인 / 질투에 격노 / 주인공에게 하게체, 격하면 해라체.
- 미라벨 반 엘스트릭(Mirabel Van Elstrik, "Aunt Bel"=벨 숙모): 제르베스의 아내, 슬퍼 보임, 대장장이 요코브와 밀통 / 주인공에게 다정한 반말 제안 / 주인공 → 해요체.
- 윌러드(Willard): 경비대장, 입장 알림 → 합쇼체.
