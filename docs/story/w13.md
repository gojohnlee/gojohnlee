## 구간 13 (줄 13000–13999)
### 줄거리
- (줄 13000~) 무도회 계속: 숙모 미라벨(벨 숙모)과의 대화. 아버지 장례(Grim)를 서둘렀던 일, 줄리아나, 죽은 여동생 베르니체, 제르베스 이야기. 옆에서 제르베스가 엿듣고 끼어듦. 유령 구울이 계속 속삭이고, 주인공이 그 말에 대꾸하면 손님들이 수군댄다. 팔을 뽑는 끔찍한 장면(줄 13055~13059)은 환각.
- 갈래: 숙모를 팔짱 끼고 데려가 속삭이게 함 / 대장장이 요코브와의 밀통을 들먹여 협박 / 부탁 → 숙모가 기절하는 척해 주의를 돌려 줌(줄 13024~13027).
- (줄 13201~) 실패 갈래: 경비병·윌러드에게 쫓겨나 집으로 호송, 또는 어둠에 삼켜지는 환각.
- (줄 13221~) 그림자 걷기 상태에서 복도의 유령들과 속삭이며 대화: 구울(이 땅의 옛 주인, 불타 죽고 성 밑에 묻힘), 유령 신부(신랑을 찾음), 유령 신랑(혼례 손님들을 몰살하려는 계획을 세웠는데 신부가 방에 남아 함께 죽음).
- (줄 13276~) 경비병 처리(마비 연고·무기), 성모상이 든 서랍의 결계에 메스꺼움.
- (줄 13296~) 제르베스 집무실 수색: 상자의 크라운, 책상 밑 숫자 5-1-3-2-4, 장례 연설문, 숨은 칸의 전투 지도(북쪽 숲 마녀의 거처), 다섯 연대 병사 명부(주인공·윌러드 이름 지워짐), 핏자국 있는 양날 단검(아버지 살해 흉기 추정). (줄 13349~) 귀가 후 독백 — 성공/실패 갈래.
- (줄 13356~) 별개 퀘스트: 묘지에서 시체를 파내던 과학자 보어하벤과 만남 → 지하 실험실, 꿰매 만든 거인 몸. 과학 대 강령술 논쟁. 뇌를 구해 오는 일(학회 또는 죽은자의 문 밖 예배당 시신에서, 뼈톱 제공). 피조물이 깨어나 주인공이 데려갈 수도 있음. 이름을 가짜(미하 호르브츠, 작센)로 대는 갈래.
- (줄 13396~) 소년 페타가 멀린의 전갈을 전함(동전 주는 갈래).
- (줄 13690~) 재단사 아랄드: 무도회 옷 맞춤, 가위·인형 부탁, 아내를 구울에게 잃은 사연, 딸 소피아 걱정.
- (줄 13729~) 폭풍에 난파한 남매 어부 빌림·아나(바샤니야 마을, 돌림병, 마을 사람들의 미움). 머물지 돌아갈지 조언·피난처·돈 주기 갈래.
- (줄 13819~) 보어하벤의 피조물과 날마다 나누는 대화: "Hhhh…"→"Hell"→"Hello"로 말을 배움, 생전 기억(엎지른 우유, 빨간 코트), 따뜻한 어둠/차가운 어둠, "어릴 때 너를 알았다"(정체 추정: 주인공 주변 인물의 뇌). 친절/냉혹 선택지.
### 인물 (이 구간에 나오는 주요 인물, 대사 많은 순)
- 미라벨 반 엘스트릭(Mirabel Van Elstrik, "Aunt Bel"=벨 숙모): 남작 부인, 주인공의 숙모 / 다정·수다, 남편 눈치를 봄, 귀신 이야기에 놀라지만 숨김 / 위로 → 공격받으면 "나는 귀부인이다"며 단호 / 주인공에게 다정한 반말("얘야"), 화나면 엄한 반말 / 주인공 → 해요체("벨 숙모").
- 보어하벤(Boerhaaven, Egger Boerhaaven): 마른스 출신 고아 과학자, 시체 도굴꾼, 네덜란드 학자 헤르만 부르하버의 사촌 / 쾌활·능청, "my dear [formal]", 과학 맹신, 미신 경멸, 외눈 안경 / 주인공을 동지로 여김, 뇌를 짓밟으면 격노 / 주인공에게 하오체 또는 해요체+"친애하는 [formal]" 제안(점잖은 연장자의 유쾌한 존대) / 주인공 → 해요체, 거만한 선택지는 반말 섞임.
- 보어하벤의 피조물(Boerhaaven's Creature): 꿰매 만든 언데드 / 한두 낱말, 아이 같은 말 / 반말, 짧게 끊어 / 주인공 → 반말(돌보거나 윽박지름).
- 제르베스(Jervase): 백부, 아내 대화에 끼어들어 경고 / 주인공에게 반말, 경비병에게 명령조.
- 유령 구울·신부·신랑(Ghost Ghoul/Bride/Groom): 구울은 집착·유혹("내 곁에 영원히"), 신부는 혼란, 신랑은 죄책감 / 반말·해라체. 주인공은 속삭이는 반말.
- 빌림(Vilim)·아나(Ana): 오스만·달마티아 혼혈 남매 어부 / 빌림은 낙천·의리, 아나는 냉소·현실적, 서로 반말("오빠/누나" 관계는 원문상 brother/sister만 — 빌림이 손위인지 불명) / 주인공에게 공손한 해요체("친절한 [formal]") / 주인공 → 해요체.
- 아랄드(Arald Tailor, 재단사 아랄드): 소피아의 아버지, 주인공을 어릴 적부터 앎 / 푸근함 / 주인공에게 다정한 반말([lad] 토큰 유지) / 주인공 → 해요체.
- 페타(Peta): 심부름하는 거리 아이 / 사투리("nuffin'"), [informal]/[formal] 토큰 / 주인공에게 어설픈 존댓말 / 주인공 → 반말.
- 윌러드(Willard): 경비대장, 주인공을 정중히 내보내며 경고 → 합쇼체.
