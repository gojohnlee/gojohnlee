## 구간 21 (줄 21000–21999)
### 줄거리
- (줄 21000~) 고아원 입양 이야기의 끝. 입양을 원하는 부부 마리야·스타니슬라브와 교장 루커스(주인공의 사촌) 앞에서 주인공이 아이들 우두머리(로빈 또는 레론, `[$SchoolLessons.KidsLeaderName]`)에 대해 좋은 말·나쁜 말을 고른다. 이어 아이를 데리러 가서 도망치라고 부추기거나 입양을 권한다. 결과는 갈래: 입양 성사(아이 첩자망 끝) / 아이가 달아나 무산(루커스가 주인공을 꾸짖고 교사직 해임).
- (줄 21130~) 다리에서 저항군 마부 클라우스가 경고: 성문이 닫혔고 주인공은 마른스에서 수배됨, 저택이 수색당해 강령술 물건이 나옴. 어머니 줄리아나·하인은 투옥, 디드리크·소피아·연인([lover])도 심문. 저항군은 와해, 클라우스는 떠난다.
- (줄 21155~) 영혼 잘라와의 결속이 끊어지거나(억지로 붙잡다 실패) 스스로 풀어 준다. 이어 주인공의 긴 독백(고립·복수·권력·아버지의 책) — 여러 갈래의 마음가짐 선택지.
- (줄 21216~) 클라우스: 도시 봉쇄, 병영에 역병. (줄 21220~) 아그네스 카넬 부인이 경비대가 잡으러 온다고 알림. 옛 정사 관계면 함께 저택에 가서 마지막 정사(갈래).
- (줄 21253~) 의식에 쓸 아기 피: 바르바라·야네즈 부부와 아기 기젤라. 바르바라의 목걸이(속이 빈 펜던트, 아기 피를 담음)는 주인공 아버지가 준 것 — 아기가 아버지의 자식일 수 있음(《끝없는 밤의 의식》에 필요). 협박·마법·폭력·목걸이 되찾아 주기 등 갈래.
- (줄 21338~) 목걸이 수소문: 해고된 정원사 니코스(아버지의 강령술·애인들 폭로), 병원 경비였던 헨닝·군터·조반니(폰 잘펠덴 박사 교수형 애도), 술 취한 도적 플로리얀·루드비크, 범인 로사 달 파라(협박·뇌물 15크라운·설득으로 회수). 콘스탄틴 신부에게 성스러운 부적을 강요.
- (줄 21497~) 고아 이다가 부모 잃고 생일에 울음. 장례(Grim)에서 시신의 수의(죽음의 천)를 얻으려 케이크로 레론을 꾀거나, '바바이' 무서운 이야기로 아이들을 속여 훔치게 함. 바바이 자장가 장면.
- (줄 21712~) 페타 손의 검은 종기(병원 숨은 병동에서 옮은 강령술 역병). 애니에게 데려가기 / 안약·수은 약으로 치료 — 함께 쓰면 낫고, 수은만 쓰면 즉사, 안 하면 교수대 아래서 죽음(갈래).
- (줄 21835~) 디드리크의 연애 조언 → 상인 카를로트에게 소풍 주문(6/18크라운) → 연인(애니 또는 코너)과 북동 숲 소풍. '기프볼' 꽃, '바스락거리는 숲'의 목소리가 연인에게 상처 주라고 속삭임. 연인이 다른 상대(라몬·레오나르도·비토리아, 사모디바)에 대해 묻고 진심을 확인 — 다정/잔인 갈래. 끝에 숲에서 이다의 목소리(수상함).

### 인물 (이 구간에 나오는 주요 인물, 대사 많은 순)
- 레론(Lelon): 고아 아이들 우두머리 후보. 착하고 걱정 많음, 아버지에게 버려짐, 주인공을 [formal]/[master]로 부름 / 처음엔 따르다 속은 걸 알면 분노·상처 / 반말(아이), 주인공에게 공손한 해요체 / 주인공은 반말.
- 루커스(Lucus): 교장, 젤리그 쪽 삼촌 제르베스의 아들(사촌). 점잖고 격식체, "dear cousin" / 주인공이 아이를 해치면 실망·해임 / 주인공에게 해요체~하오체 수준의 점잖은 존댓말 제안(사촌이지만 격식 있는 말버릇) / 주인공은 해요체 또는 반말(사촌) — 일관되게 반말 제안(추정).
- 클라우스(Klaus): 저항군 마부. 겁먹고 원칙적, 강령술에 실망 / 주인공에게 존중하나 거리 둠 → 하오체 제안 / 주인공은 하오체나 해요체.
- 아그네스 카넬 부인(Lady Agnes Carnell): 리처드 카넬 경의 아내, 무도회의 귀부인, 주인공과 정사 관계(갈래). 주인공을 걱정 / 모욕당하면 욕설 / 주인공에게 해요체(연상 귀부인) / 주인공은 해요체.
- 바르바라(Barbara)·야네즈(Janez): 농부 부부, 아기 기젤라. 야네즈는 자기를 3인칭 "야네즈는…"으로 말함(살릴 것). 둘 다 겁먹고 적대 / 주인공에게 해요체(평민→귀족) / 주인공은 반말 또는 해요체.
- 로사 달 파라(Rosa Dal Farra): 떠나려는 가난한 여자, 목걸이 도둑, 드세고 비꼼 / 반말 섞인 거친 해요체 / 주인공은 반말.
- 니코스(Nikos): 반 엘스트릭가 옛 정원사, 해고되어 술독. 분노 / 주인공에게 거친 반말 / 주인공은 해요체.
- 애니·코너(Annie/Connor, AnnieOrConnor): 연인. 지침대로 주인공에게 해요체. 화나면 단호한 해요체.
- 로빈(Robyn): 거친 사투리 소녀 우두머리("We's", "I says") / 반말 / 주인공은 반말.
- 페타(Peta)·이다(Ida)·니크(Nicc): 고아 아이들, 반말. 니크는 주인공 탓하며 분노.
- 마리야·스타니슬라브(Marija/Stanislav): 입양 희망 부부, 상인 기질의 마리야와 감상적 남편 / 해요체.
- 카를로트(Carlotte): 시장 상인, 넉살 / 해요체. 콘스탄틴 신부: 겁먹은 젊은 사제, 로사를 걱정 / 합쇼체. 헨닝·군터·조반니: 거친 전 경비, 반말. 플로리얀·루드비크: 술 취한 도적, 굽실대는 반말 섞인 말. 잘라(Zala): 고대 영혼, 낱말 조각으로 이미지를 말함 → 명사 나열 그대로.
