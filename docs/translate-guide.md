# 네크로맨서 테일 번역 지침 (대사를 새로 옮기거나 고칠 때 기준)

**영어 원문(translation/template.csv의 EN 칸)만 보고 옮긴다.** 한글 패치 1.0은 쓰지 않는다.

## 배경
- 19세기 동유럽풍 도시 마른스(Marns). 주인공(화자 `Mandel`)은 반 엘스트릭 가문의 젊은 귀족으로, 몰래 강령술(네크로맨시)을 한다.
- `Narration` = 주인공의 1인칭 서술(해라체 "나는 …했다"). 서술에서도 주인공의 웃어른(어머니·아버지·삼촌·할머니 등)은 높인다("어머니는 편찮으셨다", "아버지가 계셨다"). 단, 숙부 제르베스는 아버지 영혼이 "제르베스가 나를 죽였다"고 밝힌 뒤(이야기 순서 9,824줄 뒤)부터 서술에서 높이지 않고, 원문 뜻을 벗어나지 않는 선에서 은은한 분노를 담는다(사용자 11-02). 주인공 대사에서도 그 뒤로는 "숙부님"·높임 없이 차갑게("숙부", 반말). "부재했다"·"~하는 것이었다" 같은 한자어·번역투 대신 쉬운 우리말. `PrologueMain` 등도 서술이면 해라체.
- 서술 끝맺음이 "~했다. ~했다. ~했다."로 줄줄이 같지 않게 한다: 짧은 문장끼리는 "~하고"·"~하자"·"~하며"로 잇고, 눈앞 장면 묘사엔 현재형("~한다")을 섞고, 가끔 "~ㄹ 뿐이었다"·"~ㄴ 셈이었다"나 명사로 맺는다. 소설체는 지키고 "~했지"·"~더라" 같은 말하는 투는 쓰지 않는다.
- 화자가 빈 칸이면 선택지·책·쪽지·안내문일 수 있다. 앞뒤 줄로 판단.

## 배경 자료
- `docs/story/wNN.md` = 대사 순서 1000줄씩의 줄거리·인물 상황(순서 = translation/dump/articy-dump.tsv에 나오는 차례, 거기 없는 ID는 template.csv 차례로 뒤에). `docs/characters.md` = 인물 125명의 성격·주인공과의 관계·말투. **번역 전에 먼저 읽고** 말투·호칭·감정·관계(사이가 좋아졌는지 나빠졌는지)를 거기에 맞춘다.
- 대화 상대는 앞뒤 줄의 화자로 판단한다(주인공 Mandel 대사의 상대 = 바로 앞뒤의 다른 화자).
- 배경 자료와 아래 "정해진 말투" 표가 다르면 표를 따른다.

## 꼭 지킬 것
1. 뜻을 정확히. 예: wake/funeral/vigil = 장례·밤샘(그림 아님), crown = 크라운(돈), keep = 성, harbourmaster = 항구장, foreman = 반장, tavern = 선술집(inn = 여관), trial = 문맥대로(재판인지 시험·시련인지 배경 자료로 판단).
2. 사람·장소 이름은 `dist/KoreanFont/names-ko.tsv` 표기를 따른다(없으면 독일·동유럽식 발음).
3. `[name]` `[title]` `[he]` `[his]` `[him]` `[child]` `[gender]` 같은 대괄호 토큰은 글자 그대로 남긴다(게임이 채움). 토큰 앞뒤로 조사 붙이기는 `[name]은(는)`처럼.
4. `<i>…</i>` 기울임은 강조된 낱말에 맞춰 남긴다. 다른 태그·⟨ ⟩·《 》·이상한 기호는 쓰지 않는다.
5. 말줄임표는 `…` 한 글자(`...` 쓰지 않음). 단락 수는 입력에 적힌 수와 **정확히** 같게. 단락은 ` / `(앞뒤 공백)로 나눈다. 빈 단락은 비워 둔다.
6. 한 인물의 말투는 상대가 같으면 끝까지 같게. 자연스러운 우리말 구어로, 번역투("~하는 것이다", "그녀는", "당신은")는 줄인다. "그녀"·"당신"은 꼭 필요할 때만.
7. 욕·거친 말, 연애·성적 묘사(성인끼리)는 원문 세기만큼. 순화하거나 빼지도, 더 노골적으로 만들지도 않는다.
9. **라틴어 주문은 한국어로 옮기고 `<i>…</i>` 기울임으로 감싼다**(사용자 11-04). 예: Mortuos resurgere… = <i>죽은 자들이여, 다시 일어나 명을 따르라. 어기면 영원히 추방되리라!</i>. 게임 속 가상 언어(외계 문자 등)·학명은 그대로.
8. **주인공 성별은 플레이어가 고른다.** 주인공을 부르거나 가리키는 말에 성별을 넣지 않는다: 아가씨·도련님·아들·딸·그녀·그(주인공일 때) 금지. dove·love·dear·pet·sweetheart 같은 애칭은 "손님"·"젊은이"·"이봐요"·"자기"처럼 성별 없는 말로. 성별이 필요하면 원문의 대괄호 토큰([title], [gender], [he] 등)을 그대로 쓴다. 다른 인물(성별이 정해진 NPC)은 원문대로.

| 디드리크 | 주인공에게 반말(단짝). 할머니에겐 존댓말. 결말의 "My [title]" 대사는 일부러 격식 |
| 애니 | 주인공에게 따뜻한 해요체(연애 중에도). 오빠 코너·아이 페타에겐 반말 |

| 게르하르트 오만(항구장) | 주인공에게 "자네"+하게체(화나면 해라체 명령). 어른·여성 상인에겐 하오체 |
| 경비병·관리 | 공적인 자리면 하오체나 합쇼체, 거칠면 해라체 |
| 아이들 | 반말 |
그 밖의 인물은 신분·나이·관계를 보고 정하고, 같은 장면 안에서 일관되게.
주인공이 처음 보는 사람·낯선 어른에게 말할 때는 상대가 아랫사람처럼 굴어도 해요체("Sorry, madam" → "죄송해요, 부인"). 친해진 뒤(배경 자료의 관계 변화 참고)에만 반말로 바꾼다.
말장난·관용구(fishy, quite the catch 등)는 뜻만 풀지 말고 우리말 말맛을 살린다.
