# 네크로맨서 테일 다시 옮기기 지침 (재번역 루프가 읽음)

원래 한국어는 기계 번역이라 오역·말투 뒤섞임이 많다. **영어 원문을 기준으로 새로 옮기고**, 기존 한국어는 참고만 한다.

## 배경
- 19세기 동유럽풍 도시 마른스(Marns). 주인공(화자 `Mandel`)은 반 엘스트릭 가문의 젊은 귀족으로, 몰래 강령술(네크로맨시)을 한다.
- `Narration` = 주인공의 1인칭 서술(해라체 "나는 …했다"). `PrologueMain` 등도 서술이면 해라체.
- 화자가 빈 칸이면 선택지·책·쪽지·안내문일 수 있다. 앞뒤 줄로 판단.

## 꼭 지킬 것
1. 뜻을 정확히. 예: wake/funeral/vigil = 장례·밤샘(그림 아님), crown = 크라운(돈), keep = 성, harbourmaster = 항구장, foreman = 반장.
2. 사람·장소 이름은 `KoreanFont/names-ko.tsv` 표기를 따른다(없으면 독일·동유럽식 발음).
3. `[name]` `[title]` `[he]` `[his]` `[him]` `[child]` `[gender]` 같은 대괄호 토큰은 글자 그대로 남긴다(게임이 채움). 토큰 앞뒤로 조사 붙이기는 `[name]은(는)`처럼.
4. `<i>…</i>` 기울임은 강조된 낱말에 맞춰 남긴다. 다른 태그·⟨ ⟩·《 》·이상한 기호는 쓰지 않는다.
5. 단락 수는 입력에 적힌 수와 **정확히** 같게. 단락은 ` / `(앞뒤 공백)로 나눈다. 빈 단락은 비워 둔다.
6. 한 인물의 말투는 상대가 같으면 끝까지 같게. 자연스러운 우리말 구어로, 번역투("~하는 것이다", "그녀는", "당신은")는 줄인다. "그녀"·"당신"은 꼭 필요할 때만.
7. 욕·거친 말은 원문 세기만큼.

## 정해진 말투
| 인물 | 말투 |
|---|---|
| 주인공(Mandel) | 윗사람·처음 보는 어른에겐 해요체, 친구·아랫사람·아이에겐 반말. 집사 알브레히트에겐 해요체 |
| 집사 알브레히트 | 주인공에게 합쇼체, "도련님/아가씨" 대신 [title]. 어머님·아버님·삼촌께서. 율리아나는 "마님", 젤리그는 "나리" |
| 디드리크 | 주인공에게 반말(단짝). 할머니에겐 존댓말. 결말의 "My [title]" 대사는 일부러 격식 |
| 애니 | 주인공에게 따뜻한 해요체(연애 중에도). 오빠 코너·아이 페타에겐 반말 |
| 코너 | 주인공에게 해요체, 동생 애니에겐 반말 |
| 게르하르트 오만(항구장) | 주인공에게 "자네"+하게체(화나면 해라체 명령). 어른·여성 상인에겐 하오체 |
| 경비병·관리 | 공적인 자리면 하오체나 합쇼체, 거칠면 해라체 |
| 아이들 | 반말 |
그 밖의 인물은 신분·나이·관계를 보고 정하고, 같은 덩어리 안에서 일관되게.

## 출력 꼴
- 한 줄에 `ID<TAB>문장`. 입력에서 `[완료]`인 줄은 쓰지 않는다. 설명·머리말 없이 줄만.
