# 네크로맨서 테일 한글화

## 게임에 넣기 (PC)
1. `설치.bat` 더블클릭 — 최신본 받기, 한글 글꼴 모드 설치, 대사 번역 넣기를 한 번에 합니다.
2. 게임을 켜고 "Localization file found … Korean.csv" 창에서 **Yes**.

## 편의 기능 모드 (한글 패치와 별개, 게임폴더 `NecroHelper`)
`설치.bat`가 같이 설치합니다. `NecroHelper` 폴더를 지우면 편의 기능만 꺼집니다.
- 성문 밖 카메라: 더 눕혀서 지평선까지, 더 멀리 볼 수 있게
- 성 밖 지도에도 내 위치 표시
- 지도에 지금 일지 '할 일'의 위치를 금색 점으로(사람은 실시간 위치)
- 빈 상자·이미 판 무덤·시체 없는 무덤은 이름이 회색
- 숨은 퀘스트 분석 준비: 대화 자료를 `NecroHelper\dialogue-graph.tsv`로 한 번 저장(게임 회사 자료라 저장소에 올리지 않음)

파일 구성과 작업 규칙은 `CLAUDE.md`에 있습니다.
