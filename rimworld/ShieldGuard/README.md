# 방패병 / Shield Guard

RimWorld **1.7.4984**, Biotech, Harmony용 1티어 방어 메카. 철기병과 별도로 켤 수 있다.

## 사용

`ShieldGuard` 폴더를 게임의 `Mods`에 넣고 Harmony → Biotech → Shield Guard 순서로 활성화한다.
기본 메카 기술 연구 후 소형 메카 배양기에서 강철 80, 부품 2, 기본 서브코어 1개로 생산한다. 대역폭 1.
방패병을 전열에 두고 적을 향하게 한다. ‘방패 방향 고정’으로 사격/이동 중 방향을 유지할 수 있고, ‘방패 회전’으로 90도씩 조절한다.
선택 시 청록색 선은 실제 차단 폭이다. 뒤쪽 아군이라도 탄도가 이 선을 지나지 않으면 보호받지 못한다.

## 초기 밸런스

- 실드 120. 마지막 차단 이후 5초 후 초당 12 회복. 완전히 깨져도 같은 지연 후 0부터 회복.
- 전방 폭 2.5칸. 아군/동맹의 탄환은 통과한다. 적 탄환은 방패와 교차하면 차단된다.
- 잔여 실드 10에 피해 30이 들어오면 탄환은 제거되고 본체가 피해 20을 일반 방어력 계산으로 받는다.
- 실드가 0이면 후속 탄환은 평소대로 진행한다. 여러 방패가 있으면 탄도상 가장 먼저 닿는 방패가 받는다.
- 약한 단발 총: 피해 5, 사거리 15.9, 준비 1초, 재사용 2초. 이동 속도 3.2.
- 측후면, 근접, 이미 발생한 폭발은 우회한다. 박격포 등 머리 위로 날아가는 투사체는 차단하지 않는다.
- EMP 피격 시 실드 소진 및 10초 정지. 사망/쓰러짐/수면/기절 상태에서는 방벽이 작동하지 않는다.
- 실드 잔량, 회복 시점, EMP 정지, 방향 고정/켜짐 상태는 저장된다.

외형은 게임 내 밀리터 그래픽에 코드로 그리는 대형 검은 방패, 테두리, 관측창, 청록색 표시등을 추가한다. 신규 몸체 텍스처는 포함하지 않는다.
일반 습격 편성은 수정하지 않는다. 전투 시스템을 교체하는 모드(Combat Extended 등), 빔/즉발 무기, 특수 투사체는 호환 검증 전이다.

## 검증

`dotnet build rimworld/ShieldGuard/Source/ShieldGuard/ShieldGuard.csproj -c Release`

`dotnet run --project tests/ShieldGuard -c Release`

실제 설치된 1.7.4984의 Projectile, Pawn, ThingWithComps API를 확인했다. 참조 빌드 및 독립 기하/피해 테스트를 수행했다. 별도 프로세스에서 설치된 게임 DLL에 Harmony 패치를 실제 적용하는 검사와 게임 XML의 상속 부모/Def 참조 검사도 통과했다.
실제 게임 전투, 저장/불러오기, 렌더링, 타 모드 조합은 별도 플레이 검증이 필요하다.

게임 내 확인 항목: 후열을 겨냥한 적 탄환 차단 / 회전 후 측후면 피격 / 실드 소진 및 회복 / 초과 피해 / EMP / 여러 방패 / 저장·불러오기 / 배양 및 무장 생성.
