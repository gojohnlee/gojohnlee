# 사냥꾼 / Huntsman

RimWorld 1.7.4985 + Biotech용 2티어 저격·사냥 메카. 다른 제작 모드와 독립적으로 사용할 수 있다.

## 사용법

1. 표준 메카 기술(Standard Mechtech)을 연구한다.
2. 대형 메카 배양기에서 사냥꾼을 생산하고 메카나이터에게 연결한다.
3. 메카 그룹을 **작업(Work)** 모드로 설정한다.
4. 동물에게 **사냥** 표시를 한다. 허용 구역 안의 접근 가능한 대상부터 자동으로 사냥한다.
5. 시체를 허용하는 보관 구역에 공간이 있으면 사냥한 시체를 운반한다. 저장 공간이 없으면 시체는 현장에 남긴다.

징집하면 일반 전투 메카처럼 저격한다. 사냥 표시 없는 동물, 금지 대상, 같은 세력의 가축, 인간은 자동 사냥하지 않는다.
사냥 지정 취소, 예약, 경로 탐색, 쓰러진 동물 마무리, 시체 운반에는 게임의 기존 사냥 작업을 사용한다.
메카는 방목 동물처럼 독립적으로 일하는 것이 아니라 메카나이터 연결·전력·작업 모드·허용 구역 조건을 따른다.
사냥감의 반격은 가능하며, 이 모드는 무적·완벽한 명중·자동 도주를 제공하지 않는다.

## 수치

| 항목 | 값 |
|---|---|
| 연구 / 배양기 | 표준 메카 기술 / 대형 메카 배양기 |
| 비용 | 강철 100, 플라스틸 50, 부품 4, 표준 서브코어 1 |
| 배양 주기 / 대역폭 | 2 / 2 |
| 이동 속도 | 3.8 |
| 체력 배율 | 0.85 (랜서 몸체) |
| 날카로움 / 둔탁함 방어 | 30% / 15% |
| 피해 / 관통 | 25 / 25% |
| 사거리 | 25 |
| 조준 / 재사용 | 3초 / 2초 |
| 명중률: 접촉·단거리·중거리·장거리 | 50% · 70% · 88% · 90% (무기 기본값) |

외형: 어두운 회색 랜서 몸체와 길게 표시되는 바닐라 저격총 그래픽. 참고 사진의 긴 총열·조준경 구성을 반영하며, 인간 병사의 신규 텍스처나 엎드리는 애니메이션은 포함하지 않는다.
일반 습격 편성이나 다른 메카·정착민의 사냥 규칙을 수정하지 않는다. 전투 시스템을 교체하는 모드 호환성은 별도 확인이 필요하다.

## 빌드

`dotnet build rimworld/Huntsman/Source/Huntsman/Huntsman.csproj -c Release`

사냥 작업 제공자만 추가한다. 바닐라 사냥 제공자의 의복 트래커 접근을 피하므로 메카의 null apparel 예외를 예방한다.
