# Speed 20x

RimWorld 1.7 / Harmony / Smart Speed 필요.

시간 버튼 왼쪽의 **20x** 버튼으로 초당 1200틱을 선택합니다 (기본 60틱 × 20).
기존 Smart Speed 단계와 설정은 유지합니다. 기존 최고 속도 버튼을 누르면 기존 900틱 설정으로 돌아갑니다.
일시정지/재개는 20x 선택을 유지하며, 다른 속도 선택은 해제합니다.
위험 상황에서는 Smart Speed의 감속 설정을 따릅니다. 실제 TPS는 PC와 정착지 부하에 따라 낮아질 수 있습니다.

게임 QA는 수행하지 않았습니다. 적용 후 게임 재시작이 필요합니다.
