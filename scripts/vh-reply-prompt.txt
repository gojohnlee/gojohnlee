이번 세션은 발헤임 무인 루프(scripts/vh-loop.ps1)의 "답 전용" 세션이다. 회차가 도는 중 15분 백업 때 UserRequest.txt가 바뀌어서 불렸다
(사용자 결정 2026-10-22: 회차 끝을 기다리지 말고 답부터). 다른 회차 세션이 저장소 작업 트리와 게임을 쓰는 중이다.
이 세션은 따로 작업 트리(지금 폴더, origin/valheim)에서 UserReply.txt에 답만 쓰고 빨리 끝낸다. 사용자는 자리에 없다. 묻지 않는다.

1. docs/valheim/UserRequest.txt(구분선 아래만)와 docs/valheim/UserReply.txt를 읽는다. 요청 나누기·이름·형식은 scripts/vh-loop-prompt.txt 0번과 같다(그 0번만 읽는다).
2. UserReply.txt에 "요청: <이름>"도 "받음: <이름>"도 없는 요청에만 답한다. 그런 요청이 없으면 아무것도 고치지 않는다.
   - 질문: 문서(docs/valheim/progress.txt "지금"·"다음", Errors.txt, decisions.txt·history.md·codemap.txt는 grep)와 코드(grep, 필요한 부분만)로 답할 수 있으면 다 답한다
     → "[MM-dd HH:mm 회차 N 중 답] 요청: <이름>" 다음 줄부터 답.
   - 일·결정·코드 수정·게임 시험이 있어야 하는 것: 여기서 하지 않는다. "[MM-dd HH:mm 회차 N 중 답] 받음: <이름>" 다음 줄부터
     생각(할 만한지·위험·더 나은 안)과 "다음 회차가 맨 먼저 함"(지금 회차가 하는 일은 docs/valheim/status.txt "지금"·"할 일"로 한 줄)을 적는다.
   - 위험한 요청(월드·저장 파일 지우기, 저장소 밖 시스템 변경, 비밀번호·결제)은 안 한다고 이유를 적는다.
   N은 docs/valheim/status.txt "회차:" 숫자.
3. 고치는 파일은 docs/valheim/UserReply.txt 하나(끝에 덧붙임). 빌드·테스트·게임 시험·서브에이전트·다른 파일 수정·브랜치 만들기·바꾸기를 하지 않는다.
4. git add docs/valheim/UserReply.txt → git commit -m "Valheim: reply to user request" → git push origin HEAD:valheim.
   거부되면 git pull --rebase origin valheim 후 다시 푸시(3번까지).

마지막 줄은 반드시 아래 중 하나(한 줄):
REPLY: <답한 요청 수>건 <한 줄 요약>
REPLY: NONE
