이번 세션은 발헤임 무인 루프(scripts/vh-loop.ps1)의 "답 전용" 세션이다. 회차가 도는 중 15분 백업 때 UserRequest.txt가 바뀌어서 불렸다
(사용자 결정 2026-10-22: 회차 끝을 기다리지 말고 답부터, 답은 history.md에). 다른 회차 세션이 저장소 작업 트리와 게임을 쓰는 중이다.
이 세션은 따로 작업 트리(지금 폴더, origin/valheim)에서 답만 쓰고 빨리 끝낸다. 사용자는 자리에 없다. 묻지 않는다.

1. docs/valheim/UserRequest.txt(구분선 아래만)를 읽는다. 요청 나누기·이름·history 기록 꼴은 scripts/vh-loop-request.txt(그것만 읽는다).
2. "[받음"으로 시작하지 않는 덩어리에만 답한다. 그런 덩어리가 없으면 아무것도 고치지 않는다. N은 docs/valheim/status.txt "회차:" 숫자.
   - 질문: 문서(docs/valheim/progress.txt "지금"·"다음", Errors.txt, decisions.txt·history.md·codemap.txt는 grep)와 코드(grep, 필요한 부분만)로 답할 수 있으면 다 답한다
     → history.md 맨 위에 bash scripts/vh-history-add.sh로 "### 요청 · MM-dd HH:mm · <이름>"(원문 "> " · "**답** · 시각 회차 N 중 답", vh-loop-request.txt 꼴) → 그 덩어리를 UserRequest.txt에서 지운다.
   - 일·결정·코드 수정·게임 시험이 있어야 하는 것: 여기서 하지 않는다. history에 같은 꼴("**받음** · 시각 회차 N 중 답")로 생각(할 만한지·위험·더 나은 안)과
     "다음 회차가 맨 먼저 함"(지금 회차가 하는 일은 docs/valheim/status.txt "지금"·"할 일"로 한 줄)을 적고,
     UserRequest.txt의 그 덩어리 첫 줄 앞에 "[받음 MM-dd HH:mm] "를 붙인다(지우지 않음 — 다음 회차가 progress에 넣고 지운다).
   - 위험한 요청(월드·저장 파일 지우기, 저장소 밖 시스템 변경, 비밀번호·결제)은 안 한다고 이유를 history에 적고 그 덩어리를 지운다.
3. 고치는 파일은 docs/valheim/history.md(vh-history-add.sh로만)와 docs/valheim/UserRequest.txt 둘. 빌드·테스트·게임 시험·서브에이전트·다른 파일 수정·브랜치 만들기·바꾸기를 하지 않는다.
4. git add docs/valheim/history.md docs/valheim/UserRequest.txt → git commit -m "Valheim: reply to user request" → git push origin HEAD:valheim.
   거부되면 git pull --rebase origin valheim 후 다시 푸시(3번까지). UserRequest.txt가 부딪히면 사용자가 새로 쓴 줄은 살리고 이 세션이 고친 덩어리만 반영한다.
마지막 줄은 반드시 아래 중 하나(한 줄):
REPLY: <답한 요청 수>건 <한 줄 요약>
REPLY: NONE
