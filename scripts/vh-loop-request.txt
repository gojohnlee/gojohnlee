사용자 요청 처리(vh-loop-prompt.txt 0번에서 요청이 있을 때만 읽음. 답 전용 세션 vh-reply-prompt.txt도 이 꼴을 쓴다)
- 요청 = docs/valheim/UserRequest.txt 구분선 아래, 빈 줄로 나뉜 덩어리. 이름 = 첫 줄(길면 앞 40자). 붙여 쓴 다른 요청 줄도 따로 요청.
- 요청마다 일을 시작하기 전에 history.md 맨 위에 bash scripts/vh-history-add.sh로(휴대폰으로 읽음, 덩어리 사이 빈 줄):
  "### 요청 · MM-dd HH:mm · <이름>" → 원문 줄마다 "> "(목록 아닌 줄이 이어지면 끝에 <br>) →
  질문이면 "**답** · MM-dd HH:mm 회차 N" + 답 전부, 일·결정이면 "**받음** · MM-dd HH:mm 회차 N" + "- " 목록(할 만한지·위험·더 나은 안·할 일 순서).
  위험한 요청(월드·저장 파일 지우기, 저장소 밖 시스템 변경, 비밀번호·결제)이나 안전 규칙과 어긋나면 하지 않고 이유를 적는다.
- 할 일이 남으면 progress "다음" 맨 앞에 "요청 <이름>: 할 일"(크면 조각). 그 덩어리를 UserRequest.txt에서 지운다(구분선·머리말은 둠).
- 바로 git pull --rebase 뒤 history.md·UserRequest.txt·progress.txt만 커밋·푸시. 부딪히면 사용자가 새로 쓴 줄은 살린다.
- "[받음 MM-dd HH:mm]"으로 시작하는 덩어리는 답 전용 세션이 이미 답한 것 → history에 다시 쓰지 말고 progress "다음" 맨 앞에 넣고 지운다.
- 결정이면 decisions.txt 맞는 절에 [사용자 날짜]로(어긋나는 옛 줄은 지우고 구상서·설계서·codemap도). 지난 NEED_USER의 답이면 그걸로 이어 간다.
- 요청 일을 끝낸 회차: bash scripts/vh-history-note.sh "<이름 앞부분>"으로 "**끝** · MM-dd HH:mm 회차 N" + "- " 목록(한 일·남은 것·못 한 이유·근거 커밋), 회차 기록 요약에 "요청 <이름> 끝".
- NEED_USER로 끝낼 때: history.md 맨 위에 "### 질문 · MM-dd HH:mm · <짧게>" + "- " 목록(끝 줄 "답은 UserRequest.txt에 써 주세요").
  답을 가져가는 회차는 vh-history-note.sh "<질문 이름>"으로 "**답 받음** · 시각 회차 N"을 붙인다.
