## 구간 25 (줄 25000–25999)
### 줄거리
- 이 구간은 대화가 아니라 **게임 UI 문자열 묶음**이다. 화자는 전부 빈 칸, 이야기 순서가 아니라 종류별로 모여 있다.
- (줄 25000~25753) **능력 판정 결과 조각**. 소문자로 시작하는 동사구("notice something.", "pick the lock.", "get fleeced.")로, 게임이 앞에 "능력 이름 + 성공/실패 + You …" 같은 틀을 붙여 완성하는 것으로 보인다(추정). 대개 성공·실패가 짝으로 붙어 있다(예: drive a hard bargain / get fleeced, pick the lock / leave it locked). 2인칭(you/your)이 기본이지만 몇 줄은 1인칭이 섞임(줄 25181 "recall a book I had read").
  - 다루는 장면은 게임 전체에 흩어져 있음: 아버지 서재 수색, 부두 일·항구장, 가넷의 술집, 고아·루커스 학교, 약초상 헤일란, 마녀 찾기, 도서관, 제르베스 무도회(가짜 손님·신랑신부 찾기), 병원 탈출, 레지스탕스 매복, 사모디바 쌍둥이, 연인 고백(줄 25699~25706, 애니/코너별), 윌러드 설득·처치(줄 25744~25751), 베네티어 판별(줄 25752~).
- (줄 25754~25928) **일지(퀘스트 목표) 문장**: 주인공 1인칭 "I need to / I should …". `<b>*…</b>`로 굵게 표시된 줄은 주요 줄거리 목표(추정). 게임 흐름이 순서대로 거의 다 들어 있어 전체 줄거리 요약 구실을 한다: 귀향·일자리 찾기 → 어머니 수면약 토르포르 → 서재·위스키 단서 → 그레이브 미스트 의식(집 보호) → 애니메이트 의식(마녀 칼·검은 양초) → 강령회(아버지 납골당, 증인 모집) → 제르베스가 아버지 살해범임을 알고 성 잠입·무도회 → 추방·레지스탕스·마녀 로사리오 → 역병·각성·회춘 의식 → 끝없는 밤의 의식(리치화) → 젤리그·알디스 편/사령술 포기 갈림 → 사자의 군단·윌러드 밀회 → 북문 결전 또는 항복.
- (줄 25929~25943) **능력치·배경·직업 설명**: Strength, Agility … Convince, 군인/외교관/학자 배경, 교사/부두 노동자/술집 일꾼 직업.
- (줄 25944~25999) **아이템 이름과 설명**(알파벳순): 메달, 호박, 무도회 옷, 책 제목(햄릿 초판, 스가랴서, 강령회 책 등).
### 인물 (이 구간에 직접 대사는 없음. 일지·판정에 자주 언급되는 사람)
- 주인공(화자 없음): 일지는 1인칭 서술 → 해라체 독백("~해야 한다", "~해 보자") 제안. 판정 조각은 2인칭 "You"지만 "당신은"은 빼고 주어 없이 동사구로("자물쇠를 땄다/따지 못했다" 꼴, 틀 문장이 확인되기 전까지 한 꼴로 통일 — 제안).
- 언급만 되는 인물(이름 표기는 names-ko.tsv): 알브레히트(집사), 가넷(술집 주인), 디드리크·소피아, 루커스(교사·사촌), 헤일란(약초상), 니코스(전 정원사), 게르하르트 오만(항구장)·드라고·라몬·플립·알폰스(부두), 이브라힘(사서), 올리비에 신부·로사 달 파라, 시빌(디드리크 할머니), 로사리오(북쪽 숲 마녀, 주인공의 스승), 스빗, 요코브(대장장이), 어빙(장의사), 도로테아(제빵사), 레론·페타·니크·로빈(고아들), 멀린, 보어하벤(과학자), 레베카, 보제나(약제사), 일로나, 콘라드 폰 잘펠덴(역병 의사), 모이차(경비병), 펜 부르니크(술집 여자), 아랄드(소피아 아버지·재단사), 이사크(농부), 윌러드, 알디스(리치), 젤리그·제르베스.
- 애니/코너: 연인 갈래 문장이 성별별로 쌍을 이룬다(줄 25699~25706, 25839~25840, 25849~25850, 25860~25861, 25977·25987).
