# 구간 요약 작업 지시 (서브에이전트용)

게임 "The Necromancer's Tale"(19세기 동유럽풍 도시 마른스, 주인공 = 화자 Mandel, 젊은 귀족, 몰래 강령술) 대사를 한국어로 다시 번역하려 한다.
번역하는 모델은 120줄씩만 보므로 이야기 흐름·인물 관계를 모른다. 그 모델이 덩어리마다 읽을 **구간 요약**을 만드는 것이 이 작업이다.

입력: /home/user/refs-n/cloud/context/src/wNN.txt (한 줄 = `줄번호|화자|영어`, 줄 순서 = 게임 데이터의 대화 흐름 순서. 화자 빈 칸 = 선택지·책·쪽지·안내문 등.
`Narration` = 주인공 1인칭 서술, `Mandel` = 주인공 대사). 파일을 **끝까지 다** 읽는다(Read를 offset/limit로 나눠서). 추측은 "(추정)"이라 적는다.
참고: /home/user/refs-n/cloud/translate-guide.md(번역 지침·정해진 말투), /home/user/refs-n/cloud/names-ko.tsv(이름 한글 표기 — 인물 이름은 이 표기로).
주인공 성별은 플레이어가 고르므로 주인공에게 성별을 붙이지 않는다. `AnnieOrConnor` = 플레이어가 고른 연인(애니 또는 코너).

출력: /home/user/refs-n/cloud/context/wNN.md (입력과 같은 번호), 한국어, 아래 꼴 그대로. 구간 하나에 1,500~3,000자.

```
## 구간 NN (줄 a–b)
### 줄거리
- 이 구간에서 일어나는 일을 흐름 순서로 6~12줄. 어느 줄번호쯤부터 어느 장면인지 "(줄 1234~)"로 표시. 대화가 여러 갈래(선택지·조건)로 나뉘면 그렇다고.
### 인물 (이 구간에 나오는 주요 인물, 대사 많은 순)
- 한글이름(영어 화자명): 정체·신분 / 성격·말버릇 / 주인공과의 관계와 이 구간에서의 감정·태도 변화 / 주인공에게 어떤 말투가 맞는지(지침 표에 있으면 그대로, 없으면 근거와 함께 제안) / 주인공이 이 인물에게 쓸 말투
### 용어
- 영어 → 한국어 제안 (names-ko.tsv에 없는 고유명사·조직·주문·물건 등, 이 구간에서 반복되는 것만)
```
다른 파일은 만들거나 고치지 않는다. 끝나면 "완료 wNN …" 한 줄만 답한다.
